# Rapport d'audit — DOS-ORL-0002 « Conduite à tenir devant une épistaxis »

- **Date** : 2026-11-19
- **Auditeurs** : AUD-01 (audit scientifique, IA) et AUD-02 (posologies, IA), indépendants du rédacteur DOS-12.
- **Version auditée** : 1.0 → **version produite : 1.1**
- **Verdict** : **audite_corrections_requises**.
  - 4 marqueurs posologiques restants : acide tranexamique oral dans la maladie de Rendu-Osler, lidocaïne avec vasoconstricteur, CCP pour antagoniser un anti-Xa, desmopressine.
  - Les recommandations SFORL n'ont été lues qu'en résumé.
- **Bilan** : 9 corrections (critiques 0, majeures 0, mineures 9). AUD-01 : 4 ; AUD-02 : 5.
- **Vérifications** :
  - résumés PubMed relus : SFORL « HTA » (grade A pour la mesure de la PA) et SFORL « antithrombotiques » (bithérapie maintenue 1 mois, si possible 3 mois ; antidotes si épistaxis non contrôlée ; pas de modification en cas d'embolisation) ;
  - résumé de NoPAC relu (496 patients, 26 services d'urgences, 43,7 % contre 41,3 %) ;
  - **synthèse HAS-GEHT 2008 sur les AVK**, téléchargée et lue en texte intégral ;

## Points vérifiés sans modification

- **Anatomie** :
  - sphénopalatine (carotide externe) et ethmoïdales (carotide interne, non embolisables) ;
  - tache vasculaire.
- **Gradation des gestes** :
  - compression d'au moins 5 min (AAO-HNSF 2020) ;
  - méchage résorbable sous antithrombotiques ;
  - endoscopie secondaire.
- **Seconde intention** : SPA, embolisation, ethmoïdale antérieure par voie canthale, angio-TDM si lésion carotidienne.
- **Maladie de Rendu-Osler** :
  - critères de Curaçao ;
  - stratégie 2020 (acide tranexamique oral, ablation ciblée, bévacizumab).
- **NoPAC** (chiffres exacts).
