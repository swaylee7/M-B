# Fiche — Maladie de Behçet (RES-MED-158)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-MINT-0002 (v1.1, statut `audite_corrections_requises`). Aucun fait nouveau ; doses identiques au dossier (PNDS 2019 relu [S4]). Cadre : critères ISG 1990 [S1] et ICBD 2014 [S2], EULAR 2018 [S3] (texte intégral non relu `[À VÉRIFIER]`), séries de l'Ouest algérien [S9] et tunisienne [S10].

## 1. Définition (2 lignes)

**Vascularite systémique de vaisseaux de taille variable, artériels ET veineux**, d'étiologie inconnue, évoluant par **poussées** : aphtose buccale récidivante quasi constante (± génitale), lésions cutanées, pathergie, et atteintes **oculaires, vasculaires, neurologiques, digestives** qui font la gravité. **Aucun marqueur biologique diagnostique** : diagnostic clinique.

## 2. Chiffres et critères à connaître

| Paramètre | Valeur à retenir |
|---|---|
| Prévalence (/100 000) [S7] | Turquie 20 à 420 ; Asie 2,1 à 19,5 ; Europe du Sud 1,5 à 15,9 ; Europe du Nord 0,3 à 4,9 ; migrants : risque du pays d'origine |
| Âge de début | 20 à 40 ans ; rare chez l'enfant et après 50 ans |
| Ouest algérien (Tlemcen, n = 61) [S9] | Sex-ratio H/F **4,08** ; début 27,2 ans ; aphtose buccale 100 % ; génitale 60 % ; pathergie **20 %** ; **œil 71,2 %** ; vasculaire 29,6 % ; neurologique 19 % ; digestif 7,5 % |
| Tunisie (n = 519) [S10] | Sex-ratio 2,7 ; génitale 87,5 % ; pathergie **51 %** ; uvéite 32,2 % ; thromboses veineuses 24,9 % ; anévrismes 3,9 % ; HLA-B51 35 % ; mortalité 2,3 % |
| HLA-B51 [S8] | **OR 5,78** ; argument de terrain, **non diagnostique**, ni critère ISG ni ICBD |
| **ISG 1990** [S1] | Aphtose buccale récidivante (**≥ 3 épisodes/12 mois**) **+ ≥ 2** : aphtose génitale, lésions oculaires, lésions cutanées, pathergie (lue à 24–48 h) |
| **ICBD 2014** [S2] | Œil 2, génital 2, buccal 2, peau 1, neuro 1, vasculaire 1, pathergie (optionnelle) 1 → **≥ 4** ; plus sensibles, un peu moins spécifiques |
| Mineures / majeures | Mineures : aphtes, peau, articulations · Majeures : uvéite postérieure/panuvéite, vascularite rétinienne, TVP (caves, sus-hépatiques, sinus), anévrismes artériels, neuro-Behçet parenchymateux, digestif ulcéré, cœur |

## 3. Démarche diagnostique

```text
Aphtose buccale récidivante (≥ 3 poussées/an)
├─ 1. Chercher : aphtose génitale (scrotum, cicatrices), pseudo-folliculite, érythème
│     noueux, œil, thromboses, neuro, digestif, arthrites ; test pathergique
├─ 2. Éliminer : carences (fer, folates, B12), maladie cœliaque, MICI, neutropénie,
│     VIH, herpès, syphilis, médicaments
├─ 3. Critères ISG 1990 / ICBD 2014
├─ 4. Bilan des atteintes graves : ophtalmologie complète (lampe à fente + fond d'œil)
│     SYSTÉMATIQUE ; écho-Doppler ; angioscanner thoracique si hémoptysie ou thrombose ;
│     IRM cérébrale ; endoscopie
└─ 5. Avant immunosuppresseurs/anti-TNF : tuberculose latente, VHB, VHC, VIH

Thrombose veineuse + HÉMOPTYSIE chez un homme jeune → NE PAS ANTICOAGULER À L'AVEUGLE
   → angioscanner : anévrisme artériel pulmonaire ?
       OUI : corticoïdes forte dose + cyclophosphamide ; embolisation si grave ;
             anticoagulation contre-indiquée
       NON : chercher une embolie ; immunosuppresseur ± anticoagulation
```

- **Aphtes** douloureux, fond « beurre frais », halo ; mineurs (< 1 cm, 1–2 semaines), majeurs (> 1 cm, cicatriciels), herpétiformes. **Génitaux** : scrotum (le plus évocateur), cicatrice.
- **Pathergie** : piqûre intradermique stérile, papule/pustule à 24–48 h ; équivalent : pustule au point de ponction.
- **Œil** : uvéite antérieure avec **hypopion** ; **uvéite postérieure / vascularite rétinienne occlusive** → cécité ; séquelles cumulatives.
- **Vaisseaux** (principale cause de décès [S4]) : thromboses **inflammatoires adhérentes** (embolies pulmonaires rares), Budd-Chiari, sinus cérébraux ; **anévrismes des artères pulmonaires** (Hughes-Stovin), aorte, faux anévrismes aux ponctions (pathergie artérielle).
- **Neuro-Behçet** : parenchymateux (**tronc cérébral**, jonction mésodiencéphalique, LCR inflammatoire) ou thrombose veineuse cérébrale.
- **Digestif** : ulcérations **iléo-cæcales** à l'emporte-pièce (perforation) — ≠ Crohn, **tuberculose intestinale**.
- **Articulaire** : mono/oligoarthrite **non destructrice** des grosses articulations.
- **Différentiels algériens** : **tuberculose** (uvéite, méningite, iléon), **brucellose** (neuroméningée, arthrites, orchi-épididymite), herpès, syphilis ; uvéite HLA-B27 (sans hypopion), sarcoïdose, SAPL, SEP.

## 4. Traitement

### 4.1 Stratégie selon l'atteinte (EULAR 2018 [S3], PNDS 2019 [S4])

| Atteinte | Conduite |
|---|---|
| Cutanéo-muqueuse | Soins locaux, corticoïdes topiques ; **colchicine** 1re intention ; ulcérations buccales résistantes → **aprémilast** ; réfractaire : azathioprine, IFN-α, anti-TNF, thalidomide |
| Articulaire | **Colchicine** ; infiltration ; chronique : azathioprine, IFN-α, anti-TNF |
| Uvéite antérieure isolée | Traitement local ; systémique si homme jeune, début précoce |
| **Segment postérieur** | **Azathioprine, ciclosporine, IFN-α ou anti-TNF monoclonal** ; **corticoïdes toujours associés à un immunosuppresseur** ; poussée menaçant la vision : corticoïdes forte dose + **infliximab ou IFN-α** ; intravitréen en appoint |
| **TVP** | **Glucocorticoïdes + immunosuppresseur** (azathioprine, cyclophosphamide, ciclosporine) ; anticoagulant ajouté seulement si risque hémorragique faible **ET anévrisme pulmonaire exclu** ; réfractaire : anti-TNF monoclonal |
| **Anévrisme artériel** | Glucocorticoïdes forte dose + **cyclophosphamide** ; anti-TNF si réfractaire ; embolisation (pulmonaire) ; chirurgie/endoprothèse **sous immunosuppression** |
| Neuro parenchymateux | Glucocorticoïdes forte dose + azathioprine ; anti-TNF monoclonal si sévère ; **ÉVITER la ciclosporine** |
| Thrombose veineuse cérébrale | Glucocorticoïdes ; anticoagulation (EULAR : courte durée ; PNDS : 12 à 18 mois) |
| Digestif | Éliminer AINS, MICI, tuberculose ; glucocorticoïdes + 5-ASA ou azathioprine ; sévère : anti-TNF et/ou thalidomide ; chirurgie si perforation |

### 4.2 Doses (PNDS 2019 [S4])

| Molécule | Dose (dossier) | Vigilance |
|---|---|---|
| Colchicine | 1 à 2 mg/j, ≥ 3 à 6 mois avant de conclure à l'échec | Diarrhée ; insuffisance rénale, macrolides, pamplemousse |
| Aprémilast | 30 mg × 2/j après titration de 5 jours [S14] | Digestif, céphalées, amaigrissement |
| Corticoïdes, formes graves | Méthylprednisolone 500 mg/j × 3 j puis prednisone 1 mg/kg/j (≤ 80 mg/j) 3 semaines → 15–20 mg/j à 3 mois → ≤ 0,1 mg/kg/j à 6 mois | Uvéite postérieure : 0,5 à 1 mg/kg/j ; digestif ou TVP non grave : 0,5 mg/kg/j |
| Azathioprine | 2 mg/kg/j (≤ 200 mg/j ; jusqu'à 3 mg/kg/j) ; TPMT | NFS hebdomadaire le 1er mois ; **allopurinol/fébuxostat contre-indiqués** |
| Ciclosporine | 3 mg/kg/j | **Neurotoxique** (neuro-Behçet), néphrotoxicité, HTA |
| Interféron α2a | 3 millions d'unités SC 3 fois/semaine | **Jamais avec l'azathioprine** ; dépression, cytopénies |
| Infliximab / adalimumab | Infliximab 5 mg/kg S0, S2, S6 puis /6 semaines ; adalimumab 80 mg puis 40 mg/2 semaines | **ITL dépistée et traitée**, VHB/VHC/VIH |
| Cyclophosphamide | 0,7 g/m² IV/4 semaines (≤ 1,2 g ; 15 mg/kg dans l'algorithme du PNDS), 6 bolus, relais azathioprine | Gonades, vessie (Mesna), infections |
| Thalidomide | 50 à 100 mg/j | **Tératogène**, neuropathie, thromboses |

- **Divergence** : PNDS = anticoagulation curative **recommandée** dans les TVP (3 à 6 mois, plus si cave ou sus-hépatique) ; EULAR = anticoagulant « pouvant être ajouté ». Accord : **jamais sans exclusion d'un anévrisme pulmonaire**.
- **Aspirine antiagrégante** : envisagée en cas d'atteinte artérielle sténosante (PNDS).
- **Algérie** : choix anti-TNF / IFN-α selon le **risque tuberculeux** (PNDS) ; ITL : OMS 2024 (6H, 9H, 3HP, 3HR, 1HP, 4R [S15]) ; rifamycines ↓ corticoïdes et ciclosporine ; délai 4 semaines (S3 allemande [S16]) à mettre en balance avec l'urgence visuelle ; instruction 2024 [S13] à confirmer ; accès aux molécules `[À VÉRIFIER]`.
- **Grossesse** : après ≥ 12 mois de rémission (formes graves) ; colchicine poursuivie ; azathioprine, ciclosporine, anti-TNF autorisés si justifiés ; œstrogènes à éviter si atteinte vasculaire ; **thalidomide contre-indiqué**.

## 5. Surveillance et complications

- **Œil** : suivi rapproché si atteinte postérieure ; consulter en urgence si baisse de vision ou œil rouge.
- **Vaisseaux** : écho-Doppler, angioscanner ; vigilance devant toute hémoptysie.
- **Tolérance** : colchicine (NFS, rein), azathioprine (NFS, transaminases), ciclosporine (créatinine, PA, neuro), IFN (humeur, NFS, thyroïde), anti-TNF (**tuberculose même après dépistage négatif**), corticoïdes.
- **Mauvais pronostic** : **sexe masculin, début jeune**, uvéite postérieure, atteinte artérielle, neuro-parenchymateuse, digestive, **Budd-Chiari**, retard thérapeutique.
- **Complications** : rupture d'anévrisme, Budd-Chiari, thrombose cardiaque (décès) ; cécité ; séquelles neurologiques ; perforation digestive ; iatrogénie (tuberculose). Activité décroissante avec l'âge, séquelles irréversibles.
- **Prévention** : hygiène bucco-dentaire (poussées), arrêt du tabac, éviter les ponctions artérielles inutiles.

## 6. Pièges classiques

1. Porter le diagnostic sur des **aphtes buccaux isolés** sans éliminer carences, MICI, herpès, neutropénie.
2. **Exiger un test pathergique positif** (20 % seulement dans l'Ouest algérien).
3. **Exiger un HLA-B51 positif** (ni critère ISG ni ICBD).
4. **Anticoaguler une hémoptysie** chez un patient thrombosé sans angioscanner (anévrisme artériel pulmonaire).
5. Traiter une **thrombose veineuse du Behçet par anticoagulant seul**, sans immunosuppresseur.
6. **Ciclosporine** dans un neuro-Behçet parenchymateux.
7. **Corticoïdes seuls** dans une uvéite postérieure.
8. **Méconnaître une tuberculose** (uvéite, méningite, ulcérations iléo-cæcales) avant d'immunosupprimer.
9. Confondre l'**hypopion** du Behçet avec une endophtalmie ou une uvéite HLA-B27 ; oublier l'**examen ophtalmologique** chez un patient venu pour des aphtes.
10. **Thalidomide** sans contraception rigoureuse ; associer **interféron α + azathioprine** (myélotoxicité).

## 7. Moyens mnémotechniques (originaux)

- **« ISG = la bouche + 2 ; ICBD = 4 points »**.
- **« 2-2-2 / 1-1-1-1 »** (ICBD) : œil, génital, buccal = 2 ; peau, neuro, vasculaire, pathergie = 1.
- **« Behçet saigne avant de boucher »** : hémoptysie + thrombose = anévrisme pulmonaire jusqu'à preuve du contraire → angioscanner avant anticoagulation.
- **« Veine inflammatoire = immunosuppresseur d'abord »**.
- **« Ciclosporine : l'œil oui, le cerveau non »**.
- **« Colchicine pour la peau et les articulations, aprémilast pour la bouche »**.

## 8. Si je n'ai que 5 minutes

1. Vascularite de taille variable, artères ET veines ; homme jeune maghrébin = forme sévère.
2. Ouest algérien : sex-ratio 4,08, œil 71,2 %, pathergie 20 % [S9].
3. ISG 1990 : aphtose buccale (≥ 3/12 mois) + ≥ 2 ; ICBD 2014 : ≥ 4 points.
4. HLA-B51 (OR 5,78) : terrain, non diagnostique.
5. Examen ophtalmologique systématique (lampe à fente + fond d'œil).
6. Colchicine 1re intention (peau, muqueuses, articulations) ; aprémilast pour les aphtes buccaux résistants.
7. Uvéite postérieure : immunosuppresseur (azathioprine, ciclosporine, IFN-α, anti-TNF) ; jamais de corticoïdes seuls.
8. TVP : corticoïdes + immunosuppresseur ; anticoagulation seulement après exclusion d'un anévrisme pulmonaire.
9. Anévrisme : corticoïdes + cyclophosphamide ; embolisation/chirurgie sous immunosuppression.
10. Neuro-parenchymateux : pas de ciclosporine ; tuberculose dépistée avant anti-TNF.
