# Fiche — Électrophysiologie du cœur : activité électrique cardiaque (RES-SF-007)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-PHYS-0002 (v1.2, statut `audite_valide`). Aucun fait nouveau. Sciences fondamentales : **aucune posologie** (antiarythmiques : DOS-CARD-0007, § 13.2.2 ; hyperkaliémie : DOS-NEPH-0002). Seuils ESC 2022 vérifiés sur sources secondaires [S15, S16] (texte intégral [S13] non accessible pendant l'audit).

## 1. Définition (2 lignes)

Le cœur fonctionne grâce à un **signal électrique** né spontanément dans le **nœud sinusal** et propagé de proche en proche (jonctions communicantes, syncytium fonctionnel) ; le squelette fibreux étant isolant, la seule voie AV physiologique est **nœud AV – His** [S1]. Quatre propriétés : automatisme (chronotrope), conductibilité (dromotrope), excitabilité (bathmotrope), contractilité (inotrope ; lusitrope pour la relaxation).

## 2. Valeurs et formules à connaître

```text
Nernst (37 °C) :  E_ion (mV) = (61,5 / z) × log10 ([ion]ext / [ion]int)
                  ex. K+ : 61,5 × log10 (4/140) ≈ −95 mV
Bazett :          QTc = QT / √RR (RR en s)  — surcorrige en tachycardie, sous-corrige en bradycardie
Fréquence :       300 / grands carreaux entre deux R (ou 1 500 / petits carreaux)
Réentrée :        longueur d'onde = vitesse de conduction × période réfractaire < longueur du circuit
ECG :             25 mm/s (1 mm = 0,04 s ; grand carreau = 0,20 s) ; 10 mm = 1 mV ; DII = DI + DIII
```

| Ion (ext / int, mmol/L) | Potentiel d'équilibre | | Paramètre | Valeur |
|---|---|---|---|---|
| K+ (4 – 5 / ≈ 140) | **≈ −90 à −95 mV** | | Potentiel de repos ventriculaire | **≈ −85 à −90 mV** (proche de EK, IK1) |
| Na+ (≈ 140 / ≈ 10 – 15) | ≈ +60 à +70 mV | | Seuil (phase 0 rapide) | ≈ −65 à −70 mV ; pic ≈ +20 à +30 mV |
| Ca2+ (≈ 1,2 / ≈ 0,0001) | ≈ +120 mV | | Potentiel diastolique maximal nodal | **≈ −60 mV** |
| Cl- | ≈ −40 à −50 mV | | Durée du PA ventriculaire | **200 à 300 ms** (plateau 100 à 200 ms) ; PA atrial ≈ 150 – 200 ms |

| Tissu | Vitesse (m/s) | | Pacemaker | Fréquence |
|---|---|---|---|---|
| Nœud sinusal | ≈ 0,05 | | Nœud sinusal | **60 – 100/min** (intrinsèque ≈ 100/min) |
| Myocarde atrial / ventriculaire | ≈ 0,3 – 1 | | Jonction AV | **40 – 60/min** |
| **Nœud AV** | **≈ 0,02 – 0,05** (la plus lente) | | Purkinje / ventricules | **20 – 40/min** |
| **His-Purkinje** | **≈ 2 – 4** (la plus rapide) | | Retard nodal | ≈ 0,1 s |

| ECG (adulte) | Événement | Normale |
|---|---|---|
| P | dépolarisation atriale (OD puis OG) | < 0,12 s ; < 2,5 mm en DII |
| PR | conduction AV (retard nodal + His-Purkinje) | **0,12 – 0,20 s** |
| QRS | dépolarisation ventriculaire (phase 0) | **0,08 – 0,10 s** ; 0,11 à 0,119 s = bloc incomplet / trouble non spécifique ; **≥ 0,12 s = bloc complet** [S10] |
| ST | **plateau** (phase 2) | isoélectrique |
| T | repolarisation (phase 3) | concordante avec le QRS |
| QTc (AHA 2009) | systole électrique | allongé **≥ 450 ms (homme), ≥ 460 ms (femme)** ; court **≤ 390 ms** ; > 500 ms = risque de torsades [S11] |
| Axe du QRS | plan frontal | **−30° à +90°** |

## 3. Démarche — lecture systématique d'un ECG

```text
1. Identité, date, vitesse (25 mm/s), étalonnage (10 mm/mV)
2. Rythme sinusal ? (P positive en DI-DII-aVF, négative en aVR, chaque P suivie d'un QRS, PR constant)
3. Fréquence (300 / grands carreaux)
4. P : durée, amplitude, morphologie
5. PR 0,12 – 0,20 s ? (court → préexcitation ; long → BAV 1)
6. QRS : durée, axe, ondes Q, onde delta
7. ST isoélectrique ?   8. T concordante ?   9. QT/QTc, onde U
10. Synthèse avec la clinique et les électrolytes
```

**Devant un QTc allongé** : mesure manuelle (DII ou V5, fin de T par la tangente) → causes **acquises** d'abord (médicaments bloquant IKr, hypoK, hypoMg, hypoCa, bradycardie/BAV complet, ischémie, hypothyroïdie, hypothermie, AVC) → causes congénitales (syncope d'effort ou au réveil, mort subite familiale) → **QTc > 500 ms ou torsades = urgence** (arrêt des médicaments, correction K+/Mg2+, monitorage).

## 4. Mécanismes et tableaux d'interprétation

### 4.1 Potentiel d'action rapide (myocyte ventriculaire)

| Phase | Courants dominants | Événement |
|---|---|---|
| **4** | IK1, pompe Na/K | repos stable |
| **0** | **INa** (Nav1.5, SCN5A) | dépolarisation rapide |
| **1** | **Ito** | encoche, surtout épicardique |
| **2** | **ICa,L** vs IKr/IKs ; NCX | plateau ; entrée du Ca2+ déclencheur |
| **3** | **IKr**, **IKs**, puis IK1 | repolarisation finale |

- Le PA **raccourcit quand la fréquence augmente** (QT court en tachycardie).
- Nav1.5 : réactivable seulement sous ≈ −60 mV → base de la réfractérité ; **courant Na+ tardif** ↑ (SCN5A, ischémie, IC) → PA allongé [S4, S5].
- Épicarde (Ito important, PA court) se repolarise **en premier** → onde T **positive, concordante** [S5, S11].

### 4.2 Potentiel d'action lent et automatisme (nœuds)

- Pas de repos stable ; **phase 0 calcique (ICa,L)** → conduction lente ; repolarisation par IKr.
- Dépolarisation diastolique : **If** (HCN4, s'active à l'**hyperpolarisation**, modulé par l'AMPc) [S6] + **horloge calcique** (RyR2 → NCX) [S7] + ICa,T puis ICa,L + désactivation des courants K+. Part relative If/horloge calcique **débattue**.
- **Suppression par surcharge** (overdrive) : pause avant l'échappement après un arrêt sinusal.

| | Sympathique (β1, Gs, ↑ AMPc) | Parasympathique (M2, Gi, IK,ACh) |
|---|---|---|
| If / ICa,L | ↑ / ↑ | ↓ / ↓ |
| Potentiel diastolique maximal | inchangé | **hyperpolarisé** |
| Effets | chrono-, dromo-, ino-, lusitrope **positifs** | chrono- et dromotrope **négatifs** |

**Adénosine** (A1 → IK,ACh) : bloc AV transitoire ; **ivabradine** : bloque If sans effet inotrope négatif ; **atropine** : lève le frein vagal [S6, S12].

### 4.3 Canaux, gènes et pharmacologie [S4, S5]

| Courant | Gène | Point clé |
|---|---|---|
| INa | **SCN5A** | classe I ; perte de fonction : Brugada ; gain (tardif) : **QT long 3** |
| ICa,L | CACNA1C | vérapamil, diltiazem ; Timothy |
| IKr | **KCNH2** (hERG) | **cible de la plupart des médicaments allongeant le QT** ; **QT long 2** |
| IKs | **KCNQ1** + KCNE1 | réserve de repolarisation, ↑ par l'adrénaline ; **QT long 1** |
| IK1 | KCNJ2 | potentiel de repos ; Andersen-Tawil |
| IKur | KCNA5 | repolarisation **atriale** |
| IK,ATP | Kir6.2/SUR2A | s'ouvre dans l'ischémie (PA raccourci) |
| If | **HCN4** | ivabradine |
| Pompe Na/K | — | **digoxine** |

### 4.4 Périodes réfractaires et conduction

- **Absolue** (phases 0, 1, 2, début de 3) → pas de tétanisation ; **effective** un peu plus longue ; **relative** (fin de phase 3) → réentrées ; **supranormale** ; **vulnérable** ≈ sommet de T (« R sur T ») → **cardioversion synchronisée sur l'onde R**. Cellules nodales : réfractérité **post-repolarisation**.
- Vitesse de conduction ↓ par : phase 0 réduite (hyperkaliémie, ischémie, classe I), découplage (acidose, fibrose), anisotropie. Connexines : **Cx43** (myocarde), **Cx40** (oreillettes, His-Purkinje), **Cx45** (nœuds) [S14].
- Nœud AV : conduction **décrémentielle** = filtre en FA/flutter ; **voie accessoire (Kent)** = sans décrément → PR court, **onde delta**, risque de FA préexcitée rapide.
- Activation ventriculaire : **septum gauche → droite** (q en DI, aVL, V5-V6 ; r en V1), apex, endocarde → épicarde, bases en dernier, en moins de 0,1 s.
- Couplage excitation-contraction : ICa,L → RyR2 (**CICR**) → troponine C ; relaxation par SERCA2a (phospholamban) et NCX ; **digoxine** → ↑ Na+ i → ↑ Ca2+ i (inotropisme ; en excès, DAD) [S8].

### 4.5 Les trois mécanismes des arythmies

| Mécanisme | Indices | Exemples |
|---|---|---|
| **Automatisme** (normal ou anormal) | début et fin progressifs, catécholamines | tachycardie sinusale, tachycardie atriale focale, RIVA de reperfusion |
| **EAD** (phase 2-3) | PA allongé, réactivation ICa,L ; pauses, bradycardie, QT long, hypoK, hypoMg | **torsades de pointes** |
| **DAD** (après repolarisation) | surcharge calcique → RyR2 → NCX ; tachycardie, digitaliques, effort | TV bidirectionnelle (digitaliques, CPVT) |
| **Réentrée** | circuit + **bloc unidirectionnel** + **conduction lente** ; début/fin brusques | réentrée intranodale, voie accessoire, flutter, TV post-infarctus |

## 5. Applications cliniques : de l'ion à l'ECG

| Situation | Mécanisme | ECG |
|---|---|---|
| **Hyperkaliémie** | ↑ conductance IKr ; repos dépolarisé → inactivation de INa | **T amples, pointues, symétriques** → PR long, P effacées → **QRS large** → sinusoïde, FV/asystolie (corrélation imparfaite avec la kaliémie) |
| **Hypokaliémie** | ↓ conductances K+ ; hyperpolarisation **discrète** | ST ↓, T plates, **ondes U**, QT(U) long, torsades ; potentialise la toxicité digitalique |
| Hypercalcémie / **hypocalcémie** | plateau raccourci / allongé | QT court / **QT long par ST long** (T peu modifiée) |
| Hypomagnésémie | EAD | QT long, torsades |
| Ischémie | IK,ATP, K+ extracellulaire ↑, courants de lésion | sus-décalage ST (transmurale), sous-décalage (sous-endocardique) |
| BAV | Mobitz I souvent **nodal** (bénin) ; Mobitz II souvent **infranodal** (évolution vers BAV complet) | BAV 1 : PR > 0,20 s |

**Canalopathies** : QT long 1 (effort, natation), 2 (**stimulus auditif**, émotion, post-partum), 3 (**repos, sommeil**) ; Brugada type 1 : sus-décalage ST **≥ 2 mm « coved »** + T négative en V1-V2 (2e, 3e ou 4e espaces intercostaux) — fièvre, bloqueurs sodiques ; CPVT : RYR2/CASQ2, ECG de repos normal [S13].

**ESC 2022** (via [S15, S16]) : **QT long** si QTc **≥ 480 ms** sur ECG répétés **ou score > 3** ou variant pathogène (classe I) ; **β-bloquants non sélectifs** (nadolol, propranolol) ; **mexilétine** dans le QT long 3 (classe I). **Brugada** : type 1 **spontané** suffit ; type 1 **induit** exige un élément clinique (changement par rapport à 2015). **QT court** : QTc **≤ 360 ms** + autre élément.

**Antiarythmiques** (Vaughan Williams élargie, Lei 2018 [S12]) : **0** If (ivabradine) ; **I** Na+ (Ia quinidine, Ib lidocaïne/mexilétine, Ic flécaïnide/propafénone, Id ranolazine) ; **II** autonome (β-bloquants, adénosine) ; **III** K+ (amiodarone, sotalol) ; **IV** Ca2+ (vérapamil, diltiazem) ; V–VII (dont IEC, ARA2 en VII). Effets **pro-arythmiques** : torsades (III, Ia), réentrée sous Ic si cardiopathie ischémique.

**Prévention** : connaître les bloqueurs d'IKr (certains macrolides et fluoroquinolones, antipsychotiques, antiémétiques, antipaludéens, méthadone, classes III et Ia), éviter les associations, corriger K+/Mg2+, QTc avant et sous traitement chez les patients à risque ; enquête familiale devant une mort subite inexpliquée du sujet jeune [S11, S13].

## 6. Pièges classiques

1. Attribuer la **phase 0 nodale au sodium** (elle est **calcique**).
2. Croire que le **segment ST** correspond à la repolarisation rapide (c'est le **plateau**).
3. Croire que le **nœud sinusal est visible** à l'ECG de surface.
4. Inverser la conduction **la plus lente (nœud AV)** et **la plus rapide (Purkinje)**.
5. Oublier que **If s'active à l'hyperpolarisation**.
6. Dire que l'**hypokaliémie modérée dépolarise** le repos (elle hyperpolarise discrètement ; effet ECG dominant = repolarisation ralentie).
7. Attribuer à l'**hypocalcémie un allongement de T** (c'est le **ST** qui s'allonge).
8. Utiliser **Bazett sans esprit critique** en tachycardie.
9. Oublier que les médicaments allongeant le QT bloquent surtout **IKr (hERG)** ; confondre « QTc anormal » (AHA 2009) et **diagnostic de syndrome du QT long** (ESC 2022 : ≥ 480 ms ou score > 3).
10. Croire qu'une **onde T négative** est toujours pathologique (normale en aVR, souvent en V1, parfois en DIII) ; lire un QRS à 0,11 s comme normal.

## 7. Moyens mnémotechniques

- **« 0-1-2-3-4 = Na, to, Ca, Kr-Ks, K1 »** (original) : courants dominants des phases du PA ventriculaire.
- **« 100-60-40-20 »** (original) : bornes des fréquences d'échappement — sinus 60–100, jonction 40–60, ventricules 20–40/min.
- **« Le nœud AV est le péage, le Purkinje l'autoroute »** (original) : ≈ 0,02 – 0,05 m/s vs ≈ 2 – 4 m/s.
- **« QT 1-2-3 = sport, sonnerie, sommeil »** (original) : déclencheurs des QT longs 1 (effort), 2 (stimulus auditif), 3 (repos).
- **« Calcium : ST »** (original) : la calcémie joue sur le **segment ST** (court si hyper-, long si hypo-), pas sur l'onde T.

## 8. Si je n'ai que 5 minutes

1. Repos ≈ −85 à −90 mV, proche de EK (IK1) : dépend de la kaliémie.
2. Phases : 0 INa ; 1 Ito ; 2 ICa,L (plateau = ST) ; 3 IKr/IKs ; 4 IK1.
3. Nœuds : phase 0 calcique, dépolarisation diastolique (If/HCN4 + horloge calcique).
4. Sympathique ↑ AMPc/If ; vague IK,ACh ; adénosine → bloc AV ; ivabradine → If.
5. Hiérarchie 60–100 / 40–60 / 20–40 ; retard nodal ≈ 0,1 s, décrémentiel.
6. Période vulnérable = sommet de T → cardioversion synchronisée.
7. PR 0,12–0,20 s ; QRS 0,08–0,10 s (≥ 0,12 s = bloc complet) ; axe −30° à +90°.
8. QTc allongé ≥ 450 (H) / ≥ 460 ms (F) ; ESC 2022 : QT long ≥ 480 ms ou score > 3.
9. Arythmies : automatisme, EAD (torsades), DAD (digitaliques), réentrée.
10. Hyperkaliémie : T pointues → P effacées → QRS large → sinusoïde ; hypoK : ondes U.
