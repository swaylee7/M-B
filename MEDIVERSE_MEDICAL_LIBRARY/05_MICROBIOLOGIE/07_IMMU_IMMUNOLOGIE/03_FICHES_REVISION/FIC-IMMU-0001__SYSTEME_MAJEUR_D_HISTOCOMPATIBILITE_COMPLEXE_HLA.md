# Fiche — Système majeur d'histocompatibilité, complexe HLA (RES-SF-036)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-IMMU-0001 (v1.1, statut `audite_valide`). Aucun fait nouveau. Sciences fondamentales : **aucune posologie**. Aucun référentiel national algérien de greffe n'a été consulté par le dossier ; données de fréquence algériennes : CHU Mustapha [S17].

## 1. Définition (2 lignes)

Le **CMH** (chez l'homme **HLA**) est un ensemble de gènes codant des glycoprotéines qui **présentent des peptides aux lymphocytes T** : le TCR reconnaît un complexe **peptide + HLA du soi** (restriction par le CMH) [S1, S2, S3]. Son **polymorphisme extrême** en fait la principale barrière à la transplantation et le principal facteur génétique de nombreuses maladies auto-immunes et de certaines réactions médicamenteuses.

## 2. Chiffres et repères à connaître

| Paramètre | Valeur |
|---|---|
| Localisation | bras court du **chromosome 6 (6p21.3)**, ≈ 4 mégabases |
| Hors HLA | **β2-microglobuline : chromosome 15** ; chaîne invariante (CD74) : chromosome 5 |
| Polymorphisme | > **25 000 séquences alléliques** pour 45 gènes (IPD-IMGT/HLA, 2019-2020) [S9] |
| Classe I | chaîne α ≈ 44 – 45 kDa + β2m ≈ 12 kDa ; peptides **8 à 10** acides aminés (le plus souvent 9) |
| Classe II | α ≈ 33 – 35 kDa + β ≈ 28 kDa ; peptides **12 à 25** acides aminés (cœur d'environ 9 résidus) |
| Fratrie | **25 %** HLA-identiques ; **50 %** haplo-identiques ; **25 %** différents ; parent = toujours haplo-identique |
| Allo-réactivité | ≈ **1 à 10 %** des lymphocytes T réagissent contre des HLA allogéniques [S1] |
| Greffe de CSH non apparentée | compatibilité haute résolution **8/8** (A, B, C, DRB1), souvent **10/10** (+ DQB1) [S12] |
| Greffe rénale | 0 à 6 incompatibilités A, B, DR ; **DR** le plus de poids |
| Algérie [S17, S18, S19, S20] | 1 082 sujets sains (CHU Mustapha, PCR-SSP) : proximité Europe du Sud / Afrique du Nord ; SPA–B27 : **OR ≈ 14,6** (Ouest) ; DT1 : DR4 le plus associé (Tlemcen) ; déficit de classe II : mutation fondatrice **RFXANK** (≈ 2 250 ans) |
| Repères historiques | 1958 Dausset ; 1969 crossmatch positif → rejet hyperaigu [S11] ; 1973 B27 [S15] ; 1974 restriction (Zinkernagel et Doherty) [S7] ; 1987/1993 structures [S5, S6] |

## 3. Démarche — quand et comment explorer le HLA

| Outil | Principe | Usage |
|---|---|---|
| PCR-SSP / PCR-SSO | amorces / sondes | typage basse à intermédiaire résolution (donneur décédé, séries) |
| **Séquençage** (NGS) | lecture des exons | **haute résolution** : greffe de CSH |
| Typage ciblé | B27, B*57:01, DQ2/DQ8 | aide au diagnostic, pharmacogénétique |
| **Billes single antigen** (Luminex, MFI) | identification des anti-HLA | pré-greffe (recommandé par le consensus 2013 [S10]) ; antigènes « interdits », **cPRA** |
| **Crossmatch CDC** | sérum du receveur + lymphocytes du donneur + complément | **T positif par IgG anti-HLA = contre-indication** classique (rejet hyperaigu) [S11] |
| Crossmatch cytométrie / virtuel | IgG fixées / anticorps vs typage | plus sensible / allocation rapide (ne remplace pas totalement le cellulaire) |

```text
Greffe rénale : 1. ABO (l'endothélium exprime ABO) → 2. typage HLA → 3. anticorps anti-HLA (single antigen,
cPRA, suivi périodique) → donneur : crossmatch virtuel (DSA ?) → crossmatch cellulaire à la greffe
→ après greffe : DSA de novo, biopsie si dysfonction (C4d)

Greffe de CSH : typage haute résolution + DSA du receveur → fratrie (25 % par frère/sœur)
→ registres (8/8, 10/10) → haplo-identique (cyclophosphamide post-greffe) ou sang placentaire [S12]

Typage à visée diagnostique : cœliaque → sérologie d'abord, DQ2/DQ8 pour EXCLURE [S16] ;
lombalgie inflammatoire → B27 = un élément parmi d'autres ; avant abacavir → B*57:01 systématique [S13]
```

## 4. Mécanismes et tableaux

### 4.1 Organisation génomique

| Région | Gènes | Produits / rôle |
|---|---|---|
| **Classe I classique** | **HLA-A, -B, -C** | chaîne α |
| Classe I non classique | HLA-E, -F, -G ; MICA, MICB | ligands NK (CD94/NKG2A, NKG2D) ; HLA-G : tolérance fœto-maternelle |
| **Classe II** | **DR** (DRB1 très polymorphe), **DQ**, **DP** | chaînes α et β |
| Accessoires | DM, DO, **TAP1/TAP2**, PSMB8/PSMB9 (immunoprotéasome) | apprêtement et chargement |
| **Classe III** | C2, C4A, C4B, facteur B, TNF, HSP70, **CYP21A2** | complément, cytokines, 21-hydroxylase |

### 4.2 Classe I vs classe II

| | Classe I | Classe II |
|---|---|---|
| Chaînes | α + β2m | α + β |
| Sillon | **α1 + α2, fermé** | **α1 + β1, ouvert** |
| Peptides | **8 – 10** aa | **12 – 25** aa |
| Corécepteur | **CD8** (α3) | **CD4** (β2) |
| Expression | **toutes cellules nucléées** + plaquettes ; **pas les hématies matures** | **CPA professionnelles** (DC, macrophages, LB), épithélium thymique ; induite par l'**IFN-γ** (CIITA) |
| Peptides d'origine | **cytosolique** (soi, virus, tumeur) | **endocytée**, membranaire, autophagie |
| Cible | T CD8 cytotoxiques | T CD4 auxiliaires et régulateurs |

Le polymorphisme est concentré **dans le plancher et les hélices du sillon** (poches B et F) : chaque allèle sélectionne un répertoire de peptides [S1, S5].

### 4.3 Voies de présentation

```text
Classe I : protéine cytosolique → ubiquitine → protéasome/IMMUNOPROTÉASOME → TAP → RE
           (calréticuline, ERp57, TAPASINE, ERAP1/2) → surface → T CD8
Classe II : α + β + CHAÎNE INVARIANTE (CD74) → endosome (cathepsines) → CLIP
           → HLA-DM échange CLIP ↔ peptide (HLA-DO module) → surface → T CD4
Présentation croisée : cDC1 présentent des antigènes exogènes sur la classe I (virus, tumeurs)
```

- Perte de la classe I (virus, tumeurs) → lyse par les NK (« **soi manquant** »).
- **CD1** présente des lipides (NKT) ; **MR1** des métabolites de la vitamine B2 (MAIT).

### 4.4 Propriétés génétiques et nomenclature

- **Codominance** ; **transmission en haplotypes** ; **déséquilibre de liaison** (haplotype ancestral A1-B8-DR3) ; **sélection équilibrante** et avantage hétérozygote [S3, S4].
- Nomenclature 2010 [S8] : **HLA-A*02:01** — 1er champ = groupe d'allèles (≈ sérologie, basse résolution) ; **2e champ = protéine** (haute résolution) ; 3e = substitution synonyme ; 4e = non codant ; suffixe N (nul), L, S, Q.

### 4.5 Propriétés fonctionnelles

- **Restriction par le CMH** ; **éducation thymique** : sélection positive (orientation CD8/classe I, CD4/classe II), sélection négative ; **AIRE**.
- **NK** : **KIR** ↔ HLA-C (groupes C1/C2), HLA-B **Bw4** ; **CD94/NKG2A ↔ HLA-E** ; HLA-G (trophoblaste).
- **Allo-reconnaissance** : **directe** (HLA intacts du donneur sur CPA du donneur → rejet aigu cellulaire) ; **indirecte** (peptides HLA du donneur sur CPA du receveur → rejet chronique, DSA) ; semi-directe (discutée).
- **Superantigènes** : fixation **hors du sillon** (classe II + Vβ du TCR) → choc toxique.

## 5. Applications cliniques

| Rejet | Délai | Mécanisme |
|---|---|---|
| **Hyperaigu** | minutes à heures | anticorps **préformés** (anti-HLA, anti-ABO) → complément → thrombose (type II) ; prévenu par le crossmatch |
| Aigu cellulaire | jours à mois | T (voie directe) |
| Aigu humoral | jours à mois | DSA, complément, microcirculation |
| Chronique | mois à années | DSA (classe II, notamment DQ), voie indirecte → glomérulopathie d'allogreffe |

| Association | Allèle | | Pharmacogénétique | Médicament → réaction |
|---|---|---|---|---|
| Spondylarthrite, uvéite antérieure | **B27** | | **B*57:01** | **abacavir** → hypersensibilité (PREDICT-1 : 1 956 patients ; prévalence 5,6 % ; 0 % contre 2,7 %) [S13] |
| Behçet | **B51** | | **B*15:02** | **carbamazépine** → SJS/NET (Han, Taïwan) [S14] |
| Maladie cœliaque | **DQ2** (DQ2.5), **DQ8** | | A*31:01 | carbamazépine → DRESS |
| Diabète de type 1 | DR3-DQ2, **DR4-DQ8** ; DQB1*06:02 protecteur | | **B*58:01** | **allopurinol** → SJS/NET, DRESS |
| PR à ACPA | **épitope partagé** DRB1 | | B*57:01 | flucloxacilline → hépatite |
| Narcolepsie de type 1 | **DQB1*06:02** | | | |
| Birdshot | **A29** | | | |
| Psoriasis / SEP | C*06:02 / DRB1*15:01 | | | |
| Hémochromatose / HCS | **HFE** / **CYP21A2** (déséquilibre de liaison) | | | |

- **Mécanismes** : présentation préférentielle (gliadine **désamidée** par la transglutaminase → DQ2/DQ8), mimétisme moléculaire, propriétés de la molécule (B27 mal repliée, homodimères), déséquilibre de liaison. Abacavir : se loge dans la **poche F** de B*57:01 et **modifie le répertoire peptidique** [S1] (hypersensibilité retardée de type IV).
- **Limites** : association forte ≠ bon test ; VPP faible d'un allèle fréquent (B27, DQ2) ; intérêt surtout **prédictif négatif** (DQ2/DQ8) [S16].
- **Transfusion** : anti-HLA → **état réfractaire aux plaquettes** (qui expriment la classe I) ; **RFNH** = anti-HLA **du receveur** ou cytokines du produit (↓ par déleucocytation) ; **TRALI** = anti-HLA/HNA **du donneur** ; GVH transfusionnelle (donneur homozygote pour un haplotype du receveur) → irradiation.
- **Déficits** : classe II (« lymphocytes nus ») = mutations de **CIITA, RFX5, RFXAP, RFXANK** (pas des gènes HLA), autosomique récessif, déficit combiné, **greffe de CSH curative** (35 patients nord-africains [S20]) ; classe I = **TAP1, TAP2**, tapasine (infections bactériennes, bronchectasies, granulomes cutanés).
- **Grossesse** : le trophoblaste n'exprime **ni HLA-A ni HLA-B** mais HLA-C, -E, -G (NK utérines, KIR) ; allo-immunisation anti-HLA paternelle fréquente, comptant pour les futures greffes et transfusions.
- **Prévention de l'allo-immunisation** : transfusions seulement si nécessaires, produits déleucocytés ; suivi des anticorps sur liste d'attente ; programmes pour hyperimmunisés [S10].

## 6. Pièges classiques

1. Placer le gène de la **β2-microglobuline** dans le complexe HLA (chromosome 15).
2. Inverser les **corécepteurs** (CD8 ↔ classe I ; CD4 ↔ classe II) ou la **taille des peptides**.
3. Affirmer que les **hématies matures** expriment la classe I (contrairement aux plaquettes).
4. Croire que **HLA-B27 fait le diagnostic** de spondylarthrite (VPP faible).
5. Oublier que la valeur de **DQ2/DQ8** dans la maladie cœliaque est surtout **négative**.
6. Croire qu'un **parent peut être HLA-identique** à son enfant (il est haplo-identique).
7. Confondre **crossmatch** (sérum du receveur contre cellules du donneur) et **typage HLA**.
8. Attribuer le **déficit d'expression de la classe II** à une mutation des gènes HLA (ce sont des facteurs de transcription).
9. Oublier que **HLA-DM** ne présente pas de peptide mais **catalyse le chargement**.
10. Croire que la compatibilité HLA **dispense de l'ABO** en greffe d'organe ; attribuer la RFNH aux anticorps **du donneur** (c'est le TRALI).

## 7. Moyens mnémotechniques

- **« Un-Huit, Deux-Quatre »** (original) : classe **I ↔ CD8**, classe **II ↔ CD4**.
- **« Fermé-court-partout / ouvert-long-pro »** (original) : classe I = sillon **fermé**, peptides **courts**, **toutes** les cellules nucléées ; classe II = sillon **ouvert**, peptides **longs**, CPA **professionnelles**.
- **« 25-50-25 »** (original) : fratrie HLA-identique / haplo-identique / différente.
- **« B27 dos, B51 bouche, DQ2 gluten, A29 œil »** (original) : principales associations HLA-maladies.
- **« 57 abacavir, 15-02 carbamazépine, 58 allopurinol »** (original) : pharmacogénétique HLA-B.

## 8. Si je n'ai que 5 minutes

1. HLA en 6p21.3 ; classe I (A, B, C), II (DR, DQ, DP), III (complément, TNF, CYP21A2) ; β2m sur le chromosome 15.
2. Classe I : sillon fermé, 8–10 aa, CD8, toutes les cellules nucléées.
3. Classe II : sillon ouvert, 12–25 aa, CD4, CPA (IFN-γ).
4. Voie I : protéasome → TAP → tapasine ; voie II : chaîne invariante → CLIP → HLA-DM.
5. Codominance, haplotypes (25 % / 50 % / 25 % dans une fratrie), déséquilibre de liaison ; A*02:01 = 2e champ = protéine.
6. Restriction par le CMH ; NK : KIR/HLA-C, NKG2A/HLA-E, « soi manquant ».
7. Greffe rénale : ABO → HLA → anti-HLA (single antigen) → crossmatch ; CDC T positif = rejet hyperaigu.
8. CSH : 8/8 ou 10/10 haute résolution ; fratrie de référence ; haplo-identique possible.
9. B27, B51, DQ2/DQ8 (VPN), DR3/DR4, DQB1*06:02, A29.
10. B*57:01–abacavir (systématique), B*15:02–carbamazépine, B*58:01–allopurinol.
