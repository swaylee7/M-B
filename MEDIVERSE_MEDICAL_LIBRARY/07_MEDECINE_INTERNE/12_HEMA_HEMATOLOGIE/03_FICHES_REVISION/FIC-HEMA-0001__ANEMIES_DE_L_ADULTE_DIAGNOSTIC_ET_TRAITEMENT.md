# Fiche — Anémies de l'adulte (RES-MED-112)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-HEMA-0001 (v1.1, statut `audite_corrections_requises`). Aucun fait nouveau ; doses identiques au dossier. Références : **OMS 2024** (seuils d'Hb) [S1], **OMS 2020** (ferritine) [S2], BSH 2022 (fer) [S3], BSH 2014 (B12/folates) [S4], consensus AHAI [S5], **BSG 2021** (carence martiale) [S11] ; aplasie BSH 2024 [S6], thalassémie TIF [S7, S12], drépanocytose NHLBI/HAS [S8, S9]. Données algériennes surtout hospitalières `[À VÉRIFIER]`.

## 1. Définition (2 lignes)

**Diminution de la concentration d'hémoglobine** sous un seuil fixé selon l'âge, le sexe et l'état physiologique (ni le nombre de GR ni l'hématocrite). Exclure les **fausses anémies par hémodilution** (grossesse, hypervolémie, splénomégalie, immunoglobuline monoclonale abondante).

## 2. Chiffres et critères à connaître

| Seuils OMS 2024 (15–65 ans) | Anémie si Hb < | Sévère |
|---|---|---|
| Homme | **130 g/L** | < 80 g/L |
| Femme non enceinte | **120 g/L** | < 80 g/L |
| Grossesse T1 / T2 / T3 | **110 / 105 / 110 g/L** | < 70 g/L |

Ajustement au **tabac** et à l'**altitude**, pas à l'inflammation.

| Paramètre | Valeur |
|---|---|
| VGM | 80–100 fL (micro < 80 ; macro > 100) |
| TCMH / CCMH | 27–32 pg / 32–36 g/dL (CCMH ↑ : sphérocytose) |
| Réticulocytes | 25–100 G/L ; **régénérative > 120 G/L** (à distance d'une transfusion ; délai 3–5 j après hémorragie) |
| **Ferritine** | Carence si **< 15 µg/L** (OMS) ; < 30 µg/L en pratique (BSH : sensibilité) ; **< 70 µg/L si inflammation** (OMS) |
| CST | Bas < 16–20 % ; **> 45 %** = surcharge (ferritine seule insuffisante) |
| Schizocytes | **> 1 %** → microangiopathie thrombotique |
| β-thalassémie hétérozygote | VGM 60–70 fL, **GR normaux/élevés**, ferritine normale, **HbA2 > 3,5 %** |
| Drépanocytose SS | Hb de base 60–90 g/L ; aggravation aiguë = baisse ≥ 20 g/L |
| Aplasie (Camitta) | Sévère : cellularité < 25 % (ou 25–50 % avec < 30 % hématopoïétique) + ≥ 2 : PNN < 0,5 G/L, plaquettes < 20 G/L, réticulocytes < 60 G/L ; **très sévère** : PNN < 0,2 G/L |

| | Réticulocytes bas (central) | Réticulocytes élevés (périphérique) |
|---|---|---|
| **Microcytaire** | **Carence martiale**, inflammation ancienne, sidéroblastique | **Thalassémie** |
| **Normocytaire** | Inflammation, **IRC**, endocrinopathies, aplasie, envahissement, érythroblastopénie, carence mixte | **Hémorragie aiguë**, **hémolyse** |
| **Macrocytaire** | **B12/folates** (VGM souvent > 110), **myélodysplasie**, médicaments, alcool, hypothyroïdie | Hémolyse/régénération intense |

## 3. Démarche diagnostique

```text
1. TOLÉRANCE d'abord : angor, IC, hypotension, malaise/syncope/confusion, hémorragie active,
   hémolyse aiguë (urines porto) → urgence
2. Autres lignées atteintes ? → frottis + MYÉLOGRAMME ± BOM (aplasie, leucémie, envahissement)
3. Anémie isolée → VGM + RÉTICULOCYTES (+ frottis, ferritine, CST, CRP, créatinine, TSH)
   MICRO → ferritine/CST/CRP : carence → ENQUÊTE (femme réglée : gynéco ± cœliaque ;
           homme/ménopausée : FOGD + biopsies duodénales + COLOSCOPIE ; sérologie cœliaque)
           | inflammation | bilan normal + GR nombreux → ÉLECTROPHORÈSE (après correction du fer)
   NORMO arégénérative → CRP, créatinine, TSH, fer, EPP → sinon myélogramme
   MACRO arégénérative → B12, folates, TSH, hépatique, alcool, médicaments → sinon
           myélogramme + caryotype (myélodysplasie) ; B12 basse → anti-facteur intrinsèque
   RÉGÉNÉRATIVE → hémorragie aiguë | HÉMOLYSE (haptoglobine ↓, LDH ↑, bilirubine libre ↑)
           → frottis + TDA MONOSPÉCIFIQUE :
             schizocytes + thrombopénie → MAT (ADAMTS13, URGENCE)
             TDA+ IgG ± C3d → AHAI chaude (LLC, lymphome, lupus, médicament)
             TDA+ C3d seul → agglutinines froides
             TDA− → G6PD (à distance), sphérocytose, électrophorèse, HPN (CD55/CD59, FLAER),
                    paludisme (voyage)
```

| Signe | Orientation |
|---|---|
| Koïlonychie, pica, perlèche, jambes sans repos | Carence martiale |
| **Glossite de Hunter**, sclérose combinée de la moelle (peut exister **sans anémie**) | Carence en B12 |
| Ictère, splénomégalie, lithiase pigmentaire | Hémolyse |
| Crises osseuses, ulcères de jambe, priapisme | Drépanocytose |
| Urines foncées du matin + thromboses insolites + cytopénies | **HPN** |
| Fèves au printemps, médicament oxydant | **G6PD** (corps de Heinz, hématies mordues) |

- **Mégaloblastose** : LDH très élevées et haptoglobine basse (hémolyse **intramédullaire**) mais **réticulocytes bas** ; leuconeutropénie, thrombopénie, PN hypersegmentés.
- **Biermer** : anti-facteur intrinsèque (spécifiques), anti-cellules pariétales (sensibles) ; FOGD (gastrite fundique, TNE, adénocarcinome). **Protoxyde d'azote** : myélopathie du jeune, B12 parfois normale (acide méthylmalonique et homocystéine ↑).

## 4. Traitement

| Situation | Traitement (dossier) |
|---|---|
| **Transfusion de CGR** | Sur tolérance, cinétique, terrain, cause ; seuils restrictifs ≈ **70 g/L** (**80 g/L** si cardiovasculaire/chirurgie lourde) `[À VÉRIFIER : HAS/ANSM, AABB]` ; **pas de transfusion d'une carence bien tolérée** ; ABO-RhD, RH-KEL, RAI < 72 h, contrôle ultime ; phénotype étendu (drépanocytose, thalassémie) |
| **Fer oral** | **1 comprimé/j** de sel ferreux (**50–100 mg de fer élémentaire**, ex. sulfate ferreux 200 mg), **à jeun** ; intolérance : **un jour sur deux** (hepcidine ↑ ≈ 24 h après chaque prise) ; durée : normalisation de l'Hb **+ 3 mois** ; réponse : réticulocytes J7–J10, **Hb + 10 g/L à 2 semaines** (ou + 20 g/L à 4 semaines) |
| **Fer IV** | Intolérance/échec, malabsorption, pertes > absorption, correction rapide (T3, préopératoire), IRC, IC ; milieu équipé (hypersensibilité) ; **carboxymaltose ferrique** : Hb < 100 g/L → **1 500 mg** (35–< 70 kg) / **2 000 mg** (≥ 70 kg) ; 100–< 140 g/L → 1 000 / 1 500 mg ; ≥ 140 → 500 mg ; < 35 kg : 30 mg/kg ; **≤ 1 000 mg par administration** (20 mg/kg perfusion ; 15 mg/kg injection), 2e dose ≥ 7 j ; hypophosphatémie ; Ganzoni non interchangeable |
| **B12** | **Hydroxocobalamine 1 mg IM × 3/semaine pendant 2 semaines**, puis **1 mg /3 mois à vie** (Biermer) ; atteinte neurologique : **1 mg un jour sur deux** jusqu'à plateau, puis **1 mg /2 mois** ; France : cyanocobalamine 1 000 µg IM `[POSOLOGIE À VÉRIFIER — RCP / protocole local]` ; voie orale forte dose possible (pas si atteinte neurologique sévère) |
| **Folates** | **Acide folique 5 mg/j × 4 mois** ; **jamais seuls sans vérifier/corriger la B12** ; **kaliémie** les premiers jours (formes sévères), réticulocytes J5–J8 |
| **AHAI chaude** | **Prednisone ≈ 1 mg/kg/j × 3–4 semaines**, décroissance sur plusieurs mois ; **rituximab** 2e ligne (ou plus tôt si sévère) ; folates ; **prophylaxie thromboembolique** |
| **Agglutinines froides** | Protection du froid ; **corticoïdes inefficaces** ; rituximab ± bendamustine ; CGR réchauffés |
| **CVO drépanocytaire** | Antalgie rapide (**morphine titrée**, PCA), hydratation sans excès, O₂ si hypoxémie, **spirométrie incitative** ; **pas de corticoïdes** |
| **STA** | **1re cause de décès** de l'adulte : O₂, antibiotiques (pneumocoque + atypiques), transfusion simple ou échange, réanimation |
| **Hydroxycarbamide** | ≥ 3 CVO/an, STA sévère/récidivant, anémie symptomatique (NHLBI) ; **15 mg/kg/j**, + 5 mg/kg/j /8 semaines, **max 35 mg/kg/j** ; NFS ; contraception |
| Drépanocytose — fond | Vaccins (pneumocoque, méningocoque, Hib, grippe, VHB), **acide folique**, **pénicilline chez l'enfant jusqu'à ≥ 5 ans** ; allogreffe = seul curatif établi |
| **Thalassémie transfusée** | Transfusions /2–5 semaines, **Hb prétransfusionnelle 95–105 g/L** (≤ 130–150 après) ; **chélation** (déféroxamine SC, défériprone : agranulocytose → NFS hebdomadaire, déférasirox : rein/foie) `[POSOLOGIE À VÉRIFIER — RCP / protocole local]` ; ferritine /3 mois, **IRM T2*** annuelle dès 8–10 ans ; luspatercept (adulte), allogreffe (enfant), thérapie génique (≥ 14 ans) |
| **Aplasie sévère** | Support (produits irradiés selon protocole), neutropénie fébrile = urgence ; **allogreffe familiale HLA-identique** (jeune) ; sinon **ATG de cheval + ciclosporine + eltrombopag** ; centre expert |
| G6PD | Arrêt de l'agent oxydant, hydratation, transfusion si mal toléré, éducation |
| MAT/PTT | **Échanges plasmatiques** (urgence) |

## 5. Surveillance et complications

- Fer oral : réticulocytes J7–J10, Hb à 4 semaines, ferritine en fin de traitement ; échec → observance, saignement persistant, malabsorption, erreur diagnostique.
- B12/folates : Hb corrigée en 6–8 semaines ; Biermer : surveillance endoscopique `[À VÉRIFIER : rythme]`.
- Hydroxycarbamide : NFS /2–4 semaines pendant la titration puis /2–3 mois ; aplasie : ciclosporinémie, clone HPN, évolution clonale.
- Complications : IC à haut débit, angor ; **séquelles neurologiques** (B12) ; hémolyse chronique (lithiase, **érythroblastopénie à parvovirus B19**, carence en folates, surcharge) ; drépanocytose (ostéonécrose, ulcères, rétinopathie SC, HTAP, néphropathie, allo-immunisation, hémolyse retardée post-transfusionnelle) ; **surcharge martiale** (thalassémie) ; aplasie → HPN, myélodysplasie, leucémie.
- Prévention : fer + folates pendant la grossesse, folates préconceptionnels, B12 chez végétaliens et opérés gastriques, **dépistage des porteurs, conseil génétique (consanguinité)**, éviction des fèves et oxydants (G6PD), vaccins chez l'asplénique.

## 6. Pièges classiques

1. Confondre **hémolyse** et **mégaloblastose** (réticulocytes bas dans la seconde).
2. Lire une **ferritine « normale »** sans la CRP.
3. Doser la **G6PD pendant la crise** (faux normal).
4. **Électrophorèse en pleine carence martiale** (HbA2 abaissée masque la β-thalassémie).
5. **Folates seuls** devant une macrocytose sans doser la B12.
6. **Transfuser** une anémie carentielle bien tolérée.
7. Attribuer la carence martiale du sujet âgé à l'alimentation ou aux AINS **sans endoscopies**.
8. Donner du **fer** à une thalassémie hétérozygote (GR nombreux, ferritine normale).
9. **Corticoïdes** dans une CVO ou dans la maladie des agglutinines froides.
10. Oublier la **kaliémie** au début du traitement d'une mégaloblastose sévère.

## 7. Moyens mnémotechniques (originaux)

- **« 130 – 120 – 110 »** : homme, femme, grossesse (T2 : 105).
- **« VGM + réticulocytes : la boussole de toute anémie »**.
- **« Micro sans fer bas, pense globine »** (électrophorèse après correction du fer).
- **« Fer bas = cherche le trou »** : toute carence martiale a une cause (tube digestif après la ménopause).
- **« B12 avant folates, sinon la moelle épinière paie »**.
- **« Hémolyse : Hapto bas, LDH haut, Bili libre, Réticulos » — « mégalo : les trois premiers, sans les réticulos »**.
- **« Fèves, fièvre, médicaments oxydants : la G6PD flambe »**.

## 8. Si je n'ai que 5 minutes

1. Hb < 130 (H) / < 120 (F) ; évaluer la tolérance et chercher une hémorragie.
2. VGM + réticulocytes absolus ; frottis.
3. Micro : ferritine (< 15–30 µg/L ; < 70 si inflammation) ; sinon électrophorèse.
4. Carence martiale : toujours une cause ; FOGD + coloscopie chez l'homme et la ménopausée.
5. Fer oral 1 prise/j (50–100 mg fer élément), + 3 mois après normalisation ; IV si échec.
6. Macro arégénérative : B12/folates ; hydroxocobalamine 1 mg IM ; folates 5 mg/j après B12.
7. Régénérative : hémolyse → TDA monospécifique, schizocytes (MAT urgente).
8. Maghreb : G6PD (fèves), β-thalassémie, drépanocytose ; STA = 1re cause de décès du drépanocytaire.
9. Aplasie : Camitta ; allogreffe ou ATG + ciclosporine + eltrombopag.
10. Ne pas transfuser une carence bien tolérée.
