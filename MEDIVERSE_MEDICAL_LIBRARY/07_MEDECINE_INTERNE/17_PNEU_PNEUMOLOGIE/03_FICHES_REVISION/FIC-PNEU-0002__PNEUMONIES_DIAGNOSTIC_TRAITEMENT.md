# Fiche — Pneumonies (RES-MED-040)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-PNEU-0002 (v1.1, statut `audite_corrections_requises`). Aucun fait nouveau. Référentiel principal : **SPILF/SPLF 2025** [S1] (remplace les recommandations françaises de 2010), confronté à l'**ATS/IDSA 2019** [S2]. Aucun référentiel national algérien identifié.

## 1. Définition (2 lignes)

**Pneumonie** = infection du **parenchyme pulmonaire** ; **PAC** = acquise en ville ou diagnostiquée dans les **48 premières heures** d'hospitalisation ; PAH/PAVM = **≥ 48 h** après l'admission/l'intubation. Diagnostic = signes d'infection respiratoire basse + **opacité parenchymateuse nouvelle** à l'imagerie.

## 2. Chiffres et critères à connaître

| Paramètre | Valeur |
|---|---|
| CRB-65 / CURB-65 | **C**onfusion, **U**rée > 7 mmol/L (CURB seulement), **R** FR ≥ 30/min, **B** PAS < 90 ou PAD ≤ 60 mmHg, âge ≥ **65** |
| Mortalité à 30 j (CURB-65) | ≈ 0,7 % (score 0) → 57 % (score 5) [S6] |
| Usage courant | CRB-65 = 0 → ambulatoire possible ; ≥ 1 → évaluation hospitalière ; CURB-65 ≥ 3 → PAC grave `[À VÉRIFIER : seuils retenus par S1]` |
| PSI (Fine) | 5 classes : ≈ 0,1 % (I) → ≈ 27 % (V) ; I–III ambulatoire/courte hospitalisation [S7] |
| PAC grave ATS/IDSA | **1 majeur** (choc avec vasopresseurs, ventilation mécanique) ou **≥ 3 mineurs** (FR ≥ 30, PaO₂/FiO₂ ≤ 250, multilobaire, confusion, urée ↑, leucocytes < 4 000, plaquettes < 100 000, T < 36 °C, hypotension à remplir) |
| Réévaluation | **48–72 h** |
| Durée (SPILF/SPLF 2025) | **3 j** si stable à J3 ; **5 j** si stable entre J3 et J5 ; **7 j** sinon |
| Critères de stabilité (PTC) | T ≤ 37,8 °C, FC < 100, FR < 24, PAS ≥ 90, SpO₂ ≥ 90 % en air, conscience normale `[À VÉRIFIER : liste exacte dans S1]` |
| ECBC significatif | > 10⁷ UFC/mL (expectoration de bonne qualité) |
| Hydrocortisone (CAPE COD) | 200 mg/j IV, mortalité J28 6,2 % vs 11,9 % [S4] |

| Contexte | Agents probables |
|---|---|
| Jeune sans comorbidité | Pneumocoque, *Mycoplasma*, *Chlamydophila*, virus |
| Âgé/comorbidités | Pneumocoque, *H. influenzae*, entérobactéries, *S. aureus* |
| PAC grave | Pneumocoque, ***Legionella***, *S. aureus*, entérobactéries (± *P. aeruginosa*) |
| Post-grippale | Pneumocoque, *S. aureus* (PVL : nécrosante), *H. influenzae*, streptocoque A |
| Eau en aérosol / oiseaux / bétail | *Legionella* / *C. psittaci* / *Coxiella* |

## 3. Démarche diagnostique

```text
Toux, fièvre, dyspnée, douleur thoracique, crépitants / souffle tubaire
├─ 1. Confirmer : radiographie (ou échographie si opérateur entraîné, SPILF 2025)
├─ 2. Gravité : sepsis/choc, SpO₂, CRB-65/CURB-65, comorbidités, contexte social,
│      prise orale possible
├─ 3. Microbiologie selon la gravité
│      ├─ ambulatoire : aucune systématique (PCR grippe/SARS-CoV-2 selon saison)
│      ├─ hospitalisé : hémocultures, ECBC, antigénuries (Legionella si suspicion)
│      └─ grave : tout + antigénuries pneumocoque ET Legionella, PCR virales
└─ 4. Algérie : PAC traînante/excavée → BAAR + test moléculaire (tuberculose)
```

| Arguments | Pneumocoque | Légionellose | Atypiques |
|---|---|---|---|
| Début | Brutal, frisson | Progressif 2–3 j | Progressif |
| Signes | Douleur, herpès labial | **Digestifs, confusion**, bradycardie relative | ORL, myalgies, toux traînante |
| Biologie | PNN, CRP/PCT ↑ | **Hyponatrémie**, cytolyse, **CPK ↑**, IR | Agglutinines froides (*Mycoplasma*) |
| Radio | Condensation systématisée + bronchogramme | Multifocale extensive | Interstitielle |

- Sujet âgé : confusion, chute, décompensation sans fièvre ni toux.
- **Pas de radiographie de contrôle à J3** chez un patient qui s'améliore.

## 4. Traitement

```text
NON GRAVE, ambulatoire
├─ sans comorbidité → AMOXICILLINE 1 g × 3/j (atypique suspect → macrolide)
├─ ≥ 1 comorbidité ou post-grippale → AMOXICILLINE-AC. CLAVULANIQUE 1 g × 3/j
└─ réévaluation 48–72 h ; 3/5/7 jours selon la stabilité
HOSPITALISATION EN MÉDECINE → bêta-lactamine selon comorbidités (amox ± clav, C3G)
PAC GRAVE → C3G IV (céfotaxime/ceftriaxone) + MACROLIDE dans l'heure
          + HYDROCORTISONE IV précoce ; désescalade selon documentation
Facteurs de risque de P. aeruginosa → bêta-lactamine antipyocyanique (pipéracilline-
          tazobactam, céfépime) `[POSOLOGIE À VÉRIFIER — RCP / protocole local]`
```

| Molécule | Posologie adulte (fonction rénale normale) |
|---|---|
| Amoxicilline | 1 g × 3/j |
| Amoxicilline-acide clavulanique | 1 g × 3/j |
| Ceftriaxone | 1–2 g × 1/j IV/IM |
| Céfotaxime | 1–2 g × 3/j IV `[POSOLOGIE À VÉRIFIER — RCP]` |
| Clarithromycine | 500 mg × 2/j |
| Spiramycine | 3 MUI × 3/j `[POSOLOGIE À VÉRIFIER — RCP / protocole local]` |
| Pristinamycine (allergie) | 1 g × 3/j — disponibilité en Algérie `[À VÉRIFIER]` |
| Lévofloxacine (dernier recours) | 500 mg × 1–2/j (France) ; 750 mg/j (ATS/IDSA) `[POSOLOGIE À VÉRIFIER — RCP]` |
| Oseltamivir (grippe) | 75 mg × 2/j, 5 jours |

- **Fluoroquinolones à réserver** : effets graves (tendinopathies, QT, anévrismes), écologie, **masquent une tuberculose** en pays d'endémie.
- **Légionellose** : macrolide (non grave) ; lévofloxacine ou association (grave).
- **Désescalade** vers l'amoxicilline dès que le pneumocoque est documenté.
- PAH/PAVM : prélèvement respiratoire **avant** toute modification ; probabiliste selon l'**écologie locale** ; réévaluation à 48–72 h.
- Enfant : **amoxicilline** forte dose orale (≈ 80–100 mg/kg/j en 2–3 prises) `[POSOLOGIE À VÉRIFIER — recommandations pédiatriques nationales / GPIP / RCP]`.

## 5. Surveillance et complications

- Ambulatoire : **réévaluation systématique à 48–72 h**, consignes de reconsultation. Hospitalisé : signes vitaux, SpO₂, conscience, CRP ; critères de stabilité à J3 ; relais oral dès stabilité.
- Radiographie de contrôle **à distance (≈ 2 mois)** chez le fumeur ou > 50 ans (usage français `[À VÉRIFIER : formulation exacte de S1]`) ; non systématique pour l'ATS/IDSA.
- Complications : **empyème** (drainage si pus, pH < 7,2 ou germes à l'examen direct), abcès, sepsis/choc, SDRA, localisations secondaires, **événements cardiovasculaires dans le mois**.

```text
ÉCHEC À 72 h
├─ erreur diagnostique : TUBERCULOSE, embolie pulmonaire, OAP, cancer
├─ complication : empyème, abcès, obstruction bronchique
├─ germe non couvert : Legionella (sous bêta-lactamine), S. aureus, BGN, virus
├─ traitement : dose, absorption, observance
└─ terrain : VIH méconnu, inhalation → TDM, prélèvements, ponction, fibroscopie
```

- Prévention : vaccins pneumococcique et antigrippal (≥ 65 ans, maladies chroniques, grossesse, soignants), arrêt du tabac, hygiène bucco-dentaire, entretien des réseaux d'eau (légionellose).

## 6. Pièges classiques

1. **Amoxicilline dans une légionellose** (intracellulaire : inactive).
2. **Fluoroquinolone en première intention** chez un tousseur traînant en Algérie (masque une tuberculose).
3. Oublier que l'antigénurie *Legionella* ne détecte que **L. pneumophila sérogroupe 1**.
4. Se fier au **CRB-65 seul** en ignorant une hypoxémie ou une comorbidité décompensée.
5. Prolonger systématiquement à **10–14 jours** une PAC non compliquée.
6. Confondre **PAC et pneumonie acquise à l'hôpital** (≥ 48 h, autre écologie).
7. **Radiographie de contrôle à J3** chez un patient qui s'améliore.
8. **Corticoïdes dans une PAC non grave**.
9. Négliger le **risque cardiovasculaire** du mois suivant ; oublier la **tuberculose** devant un échec.

## 7. Moyens mnémotechniques (originaux)

- **« 3-5-7, la stabilité décide »** : 3 jours si stable à J3, 5 si stable entre J3 et J5, 7 sinon.
- **« Comorbidité → clavulanate »** : amoxicilline seule si aucune comorbidité, amoxicilline-acide clavulanique dès qu'il y en a une.
- **« Grave = C3G + macrolide + hydrocortisone »** (trois briques, dans l'heure).
- **« Légionelle : sel bas, CPK hautes, ventre et tête »** : hyponatrémie, CPK élevées, signes digestifs et confusion.
- **« Quinolone = dernier recours, surtout ici »** (endémie tuberculeuse).

## 8. Si je n'ai que 5 minutes

1. PAC = ville ou < 48 h d'hospitalisation ; pneumocoque en tête.
2. Diagnostic : clinique + radiographie (échographie si opérateur entraîné).
3. Gravité : CRB-65/CURB-65, PSI, critères ATS (1 majeur ou ≥ 3 mineurs) + SpO₂ + contexte.
4. Pas de microbiologie en ambulatoire ; Legionella si grave ou suspicion.
5. Sans comorbidité : amoxicilline 1 g × 3/j ; avec : amoxicilline-clavulanate.
6. Atypique : macrolide ; fluoroquinolone en dernier recours.
7. Grave : C3G + macrolide + hydrocortisone précoce.
8. Durée 3/5/7 jours selon la stabilité (SPILF/SPLF 2025) ; ≥ 5 j pour l'ATS/IDSA.
9. Réévaluer à 48–72 h ; échec → tuberculose, empyème, germe non couvert.
10. Prévention : vaccins pneumocoque et grippe, arrêt du tabac.
