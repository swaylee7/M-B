# Fiche — Hémorragies digestives (RES-MED-017)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-GAST-0001 (v1.1, statut `audite_valide`). Aucun fait nouveau. Référentiels : ESGE 2021 (non variqueuse) [S1], ESGE 2022 et Baveno VII (variqueuse) [S2, S3], ACG 2023 (basse) [S4]. Les fréquences étiologiques sont des ordres de grandeur pédagogiques `[À VÉRIFIER]`.

## 1. Définition (2 lignes)

Issue de sang dans la lumière du tube digestif, quelle que soit l'origine ou la voie d'extériorisation. On distingue **haute** (en amont de l'angle de **Treitz**, ≈ 3/4 des cas), **basse** (côlon, rectum, anus) et **du grêle** ; la distinction **variqueuse / non variqueuse** commande toute la prise en charge initiale.

## 2. Chiffres et critères à connaître

| Paramètre | Valeur |
|---|---|
| Hématémèse | Origine **haute** quasi certaine |
| Méléna | Haute le plus souvent ; **50–100 mL** de sang suffisent ; peut persister plusieurs jours (≠ récidive) |
| Rectorragie massive + instabilité | Peut être **haute** → EOGD |
| Index de choc | FC/PAS **> 1** = alarme |
| Glasgow-Blatchford | Urée, Hb, PAS, FC ≥ 100, méléna, syncope, hépatopathie, IC (max 23) ; **≤ 1 → ambulatoire** [S1] |
| Rockall | Âge, choc, comorbidités + diagnostic et stigmates endoscopiques → mortalité |
| AIMS65 | Albumine < 30 g/L, INR > 1,5, Mental, PAS ≤ 90, âge ≥ 65 |
| EOGD non variqueuse | **≤ 24 h** (≤ 12 h systématique non recommandée) |
| EOGD variqueuse | **≤ 12 h** |
| Transfusion | Seuil **7 g/dL**, objectif **7–9** ; coronarien : ≤ 8, cible ≥ 10 ; varices : **7–8** (Baveno VII) |
| Villanueva | Survie à 6 semaines 95 % vs 91 % (restrictif) [S6] |
| Récidive | Chute d'Hb **≥ 2 g/dL**, instabilité, nouvelle extériorisation |

| Forrest | Aspect | Conduite (ESGE 2021) |
|---|---|---|
| **Ia** | Jet artériel | Hémostase endoscopique |
| **Ib** | Suintement en nappe | Hémostase endoscopique |
| **IIa** | Vaisseau visible | Hémostase endoscopique |
| **IIb** | Caillot adhérent | Discuter ablation + traitement ; IPP forte dose |
| **IIc** | Tache pigmentée | IPP, pas de geste |
| **III** | Fond propre | IPP, sortie précoce |

| Causes hautes | Causes basses |
|---|---|
| **Ulcère** (1re cause, ≈ 30–50 %), varices (10–20 %), œsophagite/gastrite, Mallory-Weiss, tumeurs, Dieulafoy | **Diverticulose**, angiodysplasies, colite ischémique, cancer/polypes, post-polypectomie, MICI, colites infectieuses, rectite radique, proctologie |

## 3. Démarche diagnostique

```text
Extériorisation (hématémèse, méléna, rectorragie) ou anémie
├─ GRAVITÉ : hémodynamique (FC, PA couché/debout, marbrures, diurèse, conscience),
│   terrain (âge, coronarien, cirrhose, antithrombotiques), activité du saignement
├─ Biologie : groupe-Rh-RAI, NFS, urée/créatinine (urée ↑ = haute), hémostase,
│   bilan hépatique/albumine, lactates, troponine-ECG, bilan infectieux si cirrhose
├─ Hépatopathie connue/suspecte → traiter COMME VARIQUEUSE jusqu'à l'endoscopie
├─ Haute → EOGD (érythromycine 250 mg IV 30–120 min avant)
└─ Basse → instable : EOGD (éliminer une origine haute) + ANGIO-TDM ;
            stable : coloscopie non urgente après préparation (score d'Oakland)
Prothèse aortique + saignement → angio-TDM en urgence (fistule aorto-digestive)
```

- L'**Hb initiale** est faussement rassurante (hémodilution en 24–72 h) ; l'**INR** n'est pas prédictif du risque hémorragique chez le cirrhotique.

## 4. Traitement

**Réanimation commune** : 2 voies veineuses (14–16 G), O₂, à jeun, cristalloïdes sans hypervolémie (PAM ≈ 65 mmHg `[À VÉRIFIER — protocole local]`), transfusion **restrictive** ; **pas d'acide tranexamique** (HALT-IT : pas de bénéfice, thromboses veineuses doublées [S7]) ; pas de sonde nasogastrique systématique.

```text
NON VARIQUEUSE (ulcère)                    VARIQUEUSE (cirrhotique)
├─ Blatchford ≤ 1 → ambulatoire            ├─ VASOACTIF dès la suspicion, 2–5 j
├─ IPP IV 80 mg puis 8 mg/h                ├─ CEFTRIAXONE 1 g/24 h (≤ 7 j)
├─ Érythromycine 250 mg IV                 ├─ Érythromycine ; lactulose
├─ EOGD ≤ 24 h                             ├─ EOGD ≤ 12 h : LIGATURE (VO),
├─ Ia/Ib/IIa → hémostase (jamais            │   cyanoacrylate (varices cardio-fundiques)
│   adrénaline seule) + IPP forte dose 72 h ├─ TIPS PRÉEMPTIF < 72 h si Child C < 14,
├─ IIc/III → IPP oral, sortie précoce        │   Child B > 7 + saignement actif, GPVH > 20
├─ Récidive → 2e endoscopie (OTSC)          ├─ Réfractaire → sonde/prothèse → TIPS sauvetage
│   → EMBOLISATION → chirurgie               └─ Prophylaxie secondaire : BBNS (propranolol,
└─ H. pylori : biopsies, refaire si négatif,    nadolol) ou carvédilol + ligatures itératives
    contrôle de l'éradication ; arrêt des AINS
```

| Molécule | Posologie (dossier) |
|---|---|
| IPP (oméprazole/ésoméprazole) | **Bolus 80 mg puis 8 mg/h, 72 h** après hémostase (alternatives : bolus IV 2×/j ou forte dose orale 2×/j) |
| Érythromycine | **250 mg IV**, 30–120 min avant l'EOGD (CI : QT long) |
| Terlipressine | **2 mg IV/4 h** 48 h puis 1 mg/4 h (surveiller natrémie ; CI relative : coronaropathie) |
| Somatostatine | Bolus 250 µg puis **250 µg/h** (jusqu'à 500 µg/h) |
| Octréotide | Bolus 50 µg puis **50 µg/h** |
| Ceftriaxone | **1 g/24 h**, jusqu'à 7 jours |

**HDB** : stratification (Oakland), angio-TDM si saignement actif → embolisation ; coloscopie non urgente si stable ; chirurgie en dernier recours (colectomie guidée par la localisation).

**Antithrombotiques** : aspirine de **prévention secondaire non interrompue** (sinon reprise en **3–5 jours**) ; aspirine de prévention primaire arrêtée ; DAPT : avis cardiologique ; AVK/AOD interrompus, antagonisation si hémorragie menaçante, **reprise de préférence dans les 7 jours** [S1, S4].

## 5. Surveillance et complications

- FC, PA, SpO₂ toutes les 15–30 min au début ; diurèse ; conscience (encéphalopathie) ; **Hb toutes les 6–12 h** pendant 24–48 h.
- Cirrhotique : l'hémorragie déclenche **encéphalopathie, infection, insuffisance rénale** → antibioprophylaxie, lactulose, surveillance rénale. Arrêter l'IPP débuté avant l'endoscopie sauf indication (Baveno VII).
- Coronarien/âgé : **infarctus de type 2** souvent indolore (troponine, ECG).
- Moyen terme : **ulcère gastrique** → EOGD de contrôle avec biopsies à 6–8 semaines ; éradication de *H. pylori* contrôlée (test respiratoire ≥ 4 sem après antibiotiques, ≥ 2 sem après IPP) ; **ligatures toutes les 1–4 semaines** jusqu'à éradication ; fer.
- Prévention : IPP si AINS chez sujet à risque ; dépistage des varices évitable si élastométrie < 20 kPa et plaquettes > 150 G/L ; carvédilol de préférence en cas d'HTP cliniquement significative (Baveno VII).

## 6. Pièges classiques

1. Se rassurer devant une **PA normale** (tachycarde, âgé, sous bêtabloquant, cirrhotique).
2. Transfuser « pour normaliser » l'Hb (récidive variqueuse, mortalité).
3. Prescrire de l'**acide tranexamique** par réflexe.
4. Poser une **sonde nasogastrique** systématique.
5. Oublier l'**antibioprophylaxie** chez le cirrhotique (même non variqueuse).
6. Retarder le **vasoactif** jusqu'à l'endoscopie chez un cirrhotique.
7. Traiter un ulcère Forrest Ia–IIa par **adrénaline seule**.
8. Conclure à l'absence de *H. pylori* sur un test négatif en phase hémorragique sous IPP.
9. Arrêter définitivement l'**aspirine de prévention secondaire** ; corriger l'INR du cirrhotique par **PFC**.
10. Prendre un **méléna persistant** pour une récidive ; oublier la **fistule aorto-digestive** chez un porteur de prothèse aortique.

## 7. Moyens mnémotechniques (originaux)

- **« 24 pour l'ulcère, 12 pour la varice »** : délais d'EOGD.
- **« 80 puis 8 pendant 72 »** : IPP bolus 80 mg puis 8 mg/h pendant 72 h.
- **« Cirrhotique qui saigne = V-A-L-L »** : **V**asoactif, **A**ntibiotique (ceftriaxone), **L**igature, **L**actulose.
- **« Blatchford ≤ 1 = à la maison »**.
- **« Le 7 partout »** : transfusion à 7 g/dL, ceftriaxone ≤ 7 jours, reprise de l'anticoagulation dans les 7 jours.
- **« Forrest : I et IIa on traite, IIc et III on laisse »**.

## 8. Si je n'ai que 5 minutes

1. Gravité = hémodynamique + terrain ; Hb initiale trompeuse.
2. Glasgow-Blatchford ≤ 1 → ambulatoire.
3. Transfusion restrictive 7 g/dL (7–9 ; varices 7–8 ; coronarien plus libéral).
4. Pas d'acide tranexamique, pas de sonde nasogastrique systématique.
5. Ulcère : IPP 80 mg + 8 mg/h, érythromycine, EOGD ≤ 24 h.
6. Forrest Ia/Ib/IIa → hémostase combinée ; récidive → endoscopie → embolisation → chirurgie.
7. Varices : vasoactif d'emblée 2–5 j + ceftriaxone + EOGD ≤ 12 h + ligature.
8. TIPS préemptif si Child C < 14 ou B > 7 avec saignement actif.
9. HDB instable : EOGD + angio-TDM ; stable : coloscopie non urgente.
10. *H. pylori* recherché et contrôlé ; aspirine secondaire maintenue ; anticoagulant repris ≈ J7.
