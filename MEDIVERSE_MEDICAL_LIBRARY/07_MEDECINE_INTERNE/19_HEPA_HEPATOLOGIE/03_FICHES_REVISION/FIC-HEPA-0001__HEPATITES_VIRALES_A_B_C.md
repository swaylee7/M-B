# Fiche — Hépatites virales A, B, C (RES-MED-019)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-HEPA-0001 (v1.2, statut `audite_corrections_requises`). Aucun fait nouveau. EASL 2025 (VHB) : texte intégral non consulté, critères détaillés `[À VÉRIFIER]` ; OMS 2024 vérifiée dans le document acquis.

## 1. Définition (2 lignes)

**Hépatite aiguë** = inflammation hépatique virale **< 6 mois**, cytolyse souvent > 10 × LSN ; **chronique** = infection **> 6 mois** (AgHBs ou ARN VHC). Le **VHA ne passe jamais à la chronicité** ; hépatite **sévère** = TP < 50 % ; **fulminante** = + **encéphalopathie** (urgence de transplantation).

## 2. Chiffres et critères à connaître

| | VHA | VHB | VHC |
|---|---|---|---|
| Génome | ARN | **ADN** (transcriptase inverse, ADNccc) | ARN |
| Transmission | **Féco-orale** | Sanguine, **sexuelle, périnatale**, intrafamiliale | **Sanguine** |
| Incubation | 2–6 sem | 6 sem–6 mois | 2 sem–6 mois |
| Chronicité | **Jamais** | **≈ 90 % néonatale**, ≈ 30 % 1–4 ans, **< 5 % adulte** | ≈ 70 % `[À VÉRIFIER]` |
| CHC | Non | Oui, **même sans cirrhose** | Sur fibrose avancée/cirrhose |
| Vaccin | Oui | Oui | **Non** |
| Traitement | Symptomatique | Suppressif | **Curatif (RVS > 95 %)** |

| AgHBs | Anti-HBc | IgM anti-HBc | Anti-HBs | Interprétation |
|---|---|---|---|---|
| − | − | − | − | Non infecté, non immunisé → vacciner |
| − | − | − | + (≥ 10 mUI/mL) | **Immunité vaccinale** |
| − | + | − | + | Infection ancienne guérie |
| + | + | **+** | − | **Hépatite B aiguë** |
| + | + | − | − | **Chronique** si > 6 mois |

| − | + | − | − | Anti-HBc isolé → ADN VHB |

| Repère | Valeur |
|---|---|
| Algérie | Endémicité **intermédiaire** (AgHBs 2–8 %) ; **2,15 %** (enquête 1998) ; **15,2 %** de cirrhoses au diagnostic [S7] ; plan national **2024-2027** |
| Phases VHB (EASL 2017) | Infection AgHBe+ (ADN > 10⁷, ALAT normales) ; hépatite AgHBe+ ; **infection AgHBe− (ADN < 2 000 UI/mL)** ; hépatite AgHBe− ; phase AgHBs− |
| Fibrose (OMS 2024) | APRI > 0,5 = ≥ F2 ; **> 1 = cirrhose** ; élastométrie > 7 kPa = ≥ F2, **> 12,5 kPa = cirrhose** |

| RVS12 | ARN VHC indétectable **12 semaines** après la fin = guérison |

## 3. Démarche diagnostique

```text
Hépatite aiguë (pré-ictère pseudo-grippal ± arthralgies-urticaire [VHB] → ictère)
├─ GRAVITÉ : TP / FACTEUR V, encéphalopathie, hypoglycémie (pas les transaminases)
│   TP < 50 % → surveillance rapprochée + contact centre de transplantation
└─ Étiologie : IgM anti-VHA | AgHBs + IgM anti-HBc | anti-VHC + ARN VHC
               | anti-VHD si AgHBs+ | IgM anti-VHE
AgHBs+ > 6 mois → AgHBe/anti-HBe, ADN VHB, ALAT répétées (≥ 3 sur 6–12 mois),
   fibrose (APRI, FIB-4, élastométrie), anti-VHD SYSTÉMATIQUE, VHC, VIH, IgG anti-VHA,
   échographie, dépistage/vaccination de l'entourage
Anti-VHC+ → ARN VHC (ou Ag core) ; ARN négatif = guéri ou faux positif
   → fibrose (F3–F4 ?), AgHBs/anti-HBc, VIH, interactions ; génotypage non indispensable
```

- Extrahépatique : VHB → périartérite noueuse, glomérulonéphrite ; VHC → **cryoglobulinémie mixte**, lymphome B, porphyrie cutanée tardive.
- Dépistage VHB : **femme enceinte**, entourage, avant **immunosuppression** (AgHBs **et** anti-HBc), hémodialysés, VIH.

## 4. Traitement

**Hépatite aiguë** : repos relatif, **arrêt de l'alcool**, pas d'hépatotoxiques ; TP/facteur V **2 fois par semaine** ; VHB aiguë sévère (TP < 50 %) → entécavir ou ténofovir ; VHA → aucun antiviral.

```text
VHB CHRONIQUE — QUI TRAITER ?
EASL 2025 : évaluation du risque (ADN, ALAT, fibrose, âge, ATCD familial) ;
  cirrhose + ADN détectable → TRAITER ; cirrhose décompensée → traiter quel que soit l'ADN
  ADN ≥ 2 000 UI/mL + ALAT > LSN et/ou fibrose significative → traiter `[À VÉRIFIER]`
OMS 2024 : ≥ F2 ou cirrhose (APRI/élastométrie) ; OU ADN > 2 000 + ALAT > LSN ;
  OU co-infection, ATCD familial CHC/cirrhose, immunosuppression, comorbidité,
  manifestations extrahépatiques ; OU ALAT persistamment anormales sans accès à l'ADN
→ ENTÉCAVIR, TDF ou TAF, durée souvent indéfinie ; JAMAIS d'arrêt chez le cirrhotique
VHC — TRAITER TOUTE PERSONNE VIRÉMIQUE (y compris aiguë) → RVS12
```

| Molécule | Posologie | Points clés |
|---|---|---|
| Entécavir | **0,5 mg/j** (naïf) ; **1 mg/j** à jeun si cirrhose décompensée | Non recommandé après échec de la lamivudine ; pas pendant la grossesse |
| Ténofovir disoproxil (TDF) | **245 mg/j** | Toxicité rénale/osseuse ; **utilisable pendant la grossesse** |
| Ténofovir alafénamide (TAF) | **25 mg/j** | Meilleure tolérance rénale/osseuse |
| Interféron pégylé alfa-2a | 180 µg/sem SC, **48 semaines** | CI : cirrhose décompensée, grossesse, psychiatrie |
| Sofosbuvir/velpatasvir | 400/100 mg/j, **12 sem** | + ribavirine si cirrhose décompensée |
| Glécaprévir/pibrentasvir | 300/120 mg/j avec repas, **8 sem** (naïf) | **CI en cirrhose décompensée** |
| SOF/VEL/voxilaprévir | 1 cp/j, 12 sem | Retraitement après échec d'AAD |
| Sofosbuvir + daclatasvir | 400 + 60 mg/j, 12 sem (24 si cirrhose compensée) | Schéma OMS, génériques |

- Lamivudine, adéfovir, telbivudine : **pas en première ligne**.
- AAD : **amiodarone CI avec sofosbuvir** ; inducteurs enzymatiques CI ; **réactivation du VHB** chez les porteurs de l'AgHBs.
- **Transmission mère-enfant** : AgHBs chez toute femme enceinte ; TDF dès 24–28 SA si ADN > 200 000 UI/mL (EASL 2017) **ou chez toute femme AgHBs+ dès le 2e trimestre (OMS 2024, corrigenda 2025)** ; nouveau-né : **vaccin < 24 h + immunoglobulines < 12 h** ; **allaitement autorisé**.
- **Immunosuppression** : AgHBs+ → prophylaxie (ETV/TDF/TAF) pendant et ≥ 12 mois après (18 mois après anti-CD20) `[durées À VÉRIFIER dans S1]` ; AgHBs−/anti-HBc+ → prophylaxie si risque élevé (rituximab, greffe de moelle).

## 5. Surveillance et complications

- Aiguë : **AgHBs à 6 mois** (guérison ou chronicité).
- VHB non traité, AgHBe− à ADN bas : ALAT tous les 6–12 mois, ADN tous les 1–2 ans, surveillance **à vie**.
- VHB traité : observance ; ADN tous les 3 mois la 1re année puis 6–12 mois ; AgHBs annuel ; créatinine/phosphore (ténofovir) ; **échographie tous les 6 mois** (cirrhose, haut risque).
- VHC : ARN à S12 ; après RVS, **fibrose avancée/cirrhose → échographie tous les 6 mois** (le risque de CHC persiste) ; dépistage des réinfections.
- Évolution : VHB → cirrhose, CHC (même sans cirrhose) ; VHC → cirrhose en 20–30 ans ; delta en surinfection → aggravation brutale.
- Prévention : VHA → hygiène, vaccin 2 doses ; **VHB → vaccination du nourrisson avec dose de naissance**, adulte 0-1-6 mois (anti-HBs ≥ 10 mUI/mL), sérovaccination, sécurité transfusionnelle ; **le vaccin VHB protège du VHD** ; VHC → pas de vaccin, « traiter pour prévenir ».

## 6. Pièges classiques

1. Confondre **anti-HBs** (immunité) et **anti-HBc** (contact).
2. Croire que des **transaminases très élevées** signent la gravité (TP/facteur V, encéphalopathie).
3. Conclure à une chronicité sur un seul AgHBs positif (il faut **6 mois**).
4. Oublier la **fenêtre sérologique**.
5. Croire qu'un **anti-VHC positif** = infection active (il faut l'ARN), ou que la guérison protège d'une réinfection.
6. **Amiodarone + sofosbuvir** ; **inhibiteur de protéase en cirrhose décompensée**.
7. **Lamivudine seule** chez un co-infecté VIH-VHB.
8. **Arrêter un analogue** chez un cirrhotique.
9. Contre-indiquer l'**allaitement** chez une mère AgHBs+ dont l'enfant est sérovacciné.
10. Arrêter le **dépistage du CHC** chez un cirrhotique guéri du VHC ; oublier l'**anti-VHD**.

## 7. Moyens mnémotechniques (originaux)

- **« s = sauvé, c = contact »** : anti-HB**s** = protégé ; anti-HB**c** = a rencontré le virus.
- **« A s'en va, B s'installe, C se guérit »** : jamais chronique / suppression au long cours / AAD curatifs.
- **« 6 mois pour dire chronique, 12 semaines pour dire guéri »** : AgHBs > 6 mois ; RVS12.
- **« Le foie grave se lit dans le facteur V, pas dans les ALAT »**.
- **« Bébé de mère B : piqûre + immunoglobulines + sein »** : vaccin < 24 h, immunoglobulines < 12 h, allaitement autorisé.

## 8. Si je n'ai que 5 minutes

1. VHA féco-oral, jamais chronique ; VHB ADN, chronique surtout si néonatal ; VHC ARN, guérissable.
2. VHB aigu : AgHBs + IgM anti-HBc ; chronique : AgHBs > 6 mois.
3. Gravité : TP/facteur V + encéphalopathie.
4. Anti-VHD chez tout porteur de l'AgHBs.
5. Traitement VHB : cirrhose + ADN détectable (EASL 2025) ; ADN ≥ 2 000 + ALAT ↑ et/ou fibrose (EASL 2017) ; OMS 2024 : fibrose ≥ F2 seule, OU ADN > 2 000 + ALAT > LSN, OU cofacteur.
6. ETV, TDF, TAF ; jamais d'arrêt chez le cirrhotique.
7. VHC : traiter tout virémique ; SOF/VEL 12 sem ou G/P 8 sem ; interactions, AgHBs.
8. Grossesse : TDF, sérovaccination, allaitement possible.
9. AgHBs + anti-HBc avant toute immunosuppression.
10. Algérie : endémicité intermédiaire, 15,2 % de cirrhoses au diagnostic, plan 2024-2027.
