# Fiche — Cirrhoses (RES-MED-020)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-HEPA-0002 (v1.1, statut `audite_corrections_requises`). Aucun fait nouveau. Référentiels : EASL 2018 (cirrhose décompensée) [S1], Baveno VII [S2], EASL 2023 (ACLF) [S3], EASL 2025 (CHC) [S4], EASL 2022 (encéphalopathie) [S13].

## 1. Définition (2 lignes)

Affection **diffuse** du foie : **fibrose mutilante** délimitant des **nodules de régénération** ; stade ultime commun des hépatopathies chroniques. Maladie **dynamique** : elle peut **régresser** quand la cause est supprimée (**recompensation** de Baveno VII) ; la **décompensation** = ascite, hémorragie par hypertension portale ou encéphalopathie patente.

## 2. Chiffres et critères à connaître

| Child-Pugh | 1 point | 2 points | 3 points |
|---|---|---|---|
| Bilirubine (µmol/L) | < 35 | 35–50 | > 50 |
| Albumine (g/L) | > 35 | 28–35 | < 28 |
| TP / INR | > 50 % / < 1,7 | 40–50 % / 1,7–2,3 | < 40 % / > 2,3 |
| Ascite | Absente | Minime/contrôlée | Modérée à abondante |
| Encéphalopathie | Absente | Grade I–II | Grade III–IV |

**A = 5–6 ; B = 7–9 ; C = 10–15.** **MELD** (bilirubine, INR, créatinine ± Na) : mortalité à 3 mois, priorisation de la greffe.

| Repère | Valeur |
|---|---|
| HTPCS | **GPVH ≥ 10 mmHg** |
| Élastométrie (Baveno VII, « règle des 5 ») | **< 10 kPa** : cACLD exclue ; 10–15 suggérée ; **> 15** très probable ; **≤ 15 + plaquettes ≥ 150 G/L** : HTPCS exclue ; **≥ 25** : HTPCS probable |
| Endoscopie évitable | **< 20 kPa et plaquettes > 150 G/L** |
| ILA | **PNN ≥ 250/mm³** |
| GASA | **≥ 11 g/L** = hypertension portale ; < 11 = autre cause (carcinose, **tuberculose**, pancréatite) |
| Protides d'ascite | **< 15 g/L** = risque d'ILA |
| IRA (ICA) | Créatinine **+26,5 µmol/L en 48 h** ou **+50 %** / base (3 mois) |
| Recompensation | Cause supprimée + plus d'ascite, d'encéphalopathie ni d'hémorragie **≥ 12 mois** + tests améliorés |
| Hyponatrémie | Restriction hydrique si **Na < 125** ; correction **≤ 8 mmol/L/24 h** |
| ACLF | Grade 1 (rein isolé…), 2 (deux défaillances), 3 (≥ 3) |

| West Haven | Description |
|---|---|
| Minime | Tests psychométriques seuls |
| I | Attention, inversion veille-sommeil |
| II | Léthargie, désorientation, **astérixis** |
| III | Somnolence, confusion majeure |
| IV | Coma |

## 3. Démarche diagnostique

```text
Découverte fortuite (thrombopénie, élastométrie) ou complication révélatrice
├─ Clinique : foie dur à bord tranchant, angiomes stellaires, érythrose palmaire,
│   splénomégalie, circulation collatérale, ascite, ictère, astérixis, sarcopénie
├─ Diagnostic : élastométrie + tests sanguins (biopsie si doute) ; échographie-Doppler
├─ BILAN ÉTIOLOGIQUE COMPLET : alcool, AgHBs/anti-HBc/ADN + anti-VHD, anti-VHC/ARN,
│   MASLD/MetALD (critères cardiométaboliques), auto-anticorps (HAI, anti-mitochondries
│   M2 = CBP), bili-IRM (CSP), CST > 45 % + C282Y (hémochromatose), céruléoplasmine
│   (Wilson < 40 ans), alpha-1-antitrypsine, Doppler (Budd-Chiari)
├─ Sévérité : Child-Pugh, MELD ; HTPCS (élastométrie, plaquettes, EOGD)
└─ Ascite → PONCTION EXPLORATRICE systématique (PNN, culture en flacons, protides, GASA)
```

## 4. Traitement

```text
TOUJOURS : traitement étiologique (abstinence, analogues VHB, AAD) ; vaccins ;
  nutrition ; éviter AINS/sédatifs ; échographie /6 mois (CHC)
COMPENSÉE
├─ sans HTPCS → étiologie + surveillance
└─ HTPCS (≥ 25 kPa, GPVH ≥ 10, varices) → CARVÉDILOL (prévenir la décompensation)
DÉCOMPENSÉE
├─ Ascite → sel 80–120 mmol/j + spironolactone ± furosémide ; paracentèse + albumine
├─ Varices → protocole DOS-GAST-0001 ; BBNS + ligatures
├─ Encéphalopathie → déclenchant + lactulose ; rifaximine si récidive
├─ IRA → albumine 1 g/kg × 2 j → SHR : terlipressine + albumine
├─ ACLF → soins intensifs, déclenchant, transplantation ?
└─ Orientation vers un centre de TRANSPLANTATION
```

| Traitement | Posologie (dossier) |
|---|---|
| Carvédilol | **6,25 mg/j → 12,5 mg/j** (max 25 mg/j dans PREDESCI) ; PAS > 90, FC > 55 |
| Propranolol | 20–40 mg × 2/j, augmentation progressive |
| Spironolactone | **100 mg/j → 400 mg/j** (paliers de 100 mg/3 j) |
| Furosémide | **40 mg/j → 160 mg/j** (paliers de 40 mg) |
| Perte de poids | ≤ 0,5 kg/j sans œdèmes ; ≤ 1 kg/j avec œdèmes |
| Albumine 20 % post-paracentèse | **8 g/L retiré si > 5 L** (EASL 2018) ; 6–8 g/L (AASLD 2021) |
| ILA | **C3G** (céfotaxime/ceftriaxone) + **albumine 1,5 g/kg J1, 1 g/kg J3** ; ponction de contrôle à 48 h |
| Prophylaxie secondaire de l'ILA | **Norfloxacine 400 mg/j** (disponibilité en Algérie `[À VÉRIFIER]`) |
| Test de remplissage (IRA) | **Albumine 1 g/kg/j (max 100 g/j), 2 jours** |
| SHR-IRA | **Terlipressine 1 mg/4–6 h** (ou 2 mg/24 h continu, jusqu'à 12 mg/24 h) + **albumine 20–40 g/j** ; noradrénaline en réanimation |
| Lactulose | Pour **2–3 selles molles/j** ; lavements si troubles de conscience |
| Rifaximine | **550 mg × 2/j** + lactulose (prévention secondaire) |
| Nutrition | ≥ **35 kcal/kg/j**, protéines **1,2–1,5 g/kg/j**, collation du soir ; **pas de restriction protéique** |
| CBP | Acide ursodésoxycholique 13–15 mg/kg/j |

- Ascite réfractaire : paracentèses itératives + albumine, **TIPS couvert** (≥ 3 grandes paracentèses/an selon Baveno VII), greffe.
- BBNS chez l'ascitique : réduire/arrêter si PAS < 90 ou PAM < 65 mmHg et/ou SHR-IRA, puis retitrer.
- Cirrhose décompensée + VHC : **sofosbuvir/velpatasvir + ribavirine** 12 sem ; **pas d'inhibiteur de protéase ni d'interféron**.
- **À éviter** : AINS, IEC/sartans (ascite), aminosides, benzodiazépines, alcool ; IPP au long cours avec prudence.
- **Transplantation** : seul traitement curatif de la cirrhose décompensée ; orientation classique dès MELD ≥ 15 `[À VÉRIFIER]` ; CHC dans les critères (Milan) ; CI : alcool actif non contrôlé, cancer extrahépatique.

## 5. Surveillance et complications

- Clinique et biologie tous les **3–6 mois** ; **échographie ± AFP tous les 6 mois** ; élastométrie périodique ; EOGD selon Baveno VII ; nutrition à chaque visite.
- Décompensation annuelle ≈ 5–7 % `[À VÉRIFIER]` ; la 1re est le plus souvent une **ascite**.
- Complications : rupture de varices, ascite, **ILA**, **SHR-IRA**, hyponatrémie, encéphalopathie, **CHC**, thrombose porte, infections bactériennes (déclencheur d'ACLF), syndrome hépatopulmonaire, sarcopénie.
- Encéphalopathie : rechercher le **facteur déclenchant** (infection, hémorragie, constipation, hypokaliémie, insuffisance rénale, diurétiques, benzodiazépines/opiacés, TIPS).
- SHR : CONFIRM → risque d'**insuffisance respiratoire** sous terlipressine (surveiller oxygénation et volémie).
- Algérie : VHB/VHC causes majeures (15,2 % de cirrhoses au diagnostic du VHB) ; transplantation limitée `[À VÉRIFIER]`.

## 6. Pièges classiques

1. Se fier à l'**INR** pour le risque hémorragique ou transfuser du plasma avant une ponction d'ascite.
2. Oublier la **ponction d'ascite** devant fièvre, douleur, encéphalopathie ou insuffisance rénale.
3. Attendre la **culture** pour traiter une ILA (PNN ≥ 250 suffisent).
4. Oublier l'**albumine** dans l'ILA ou après une grande paracentèse.
5. **Restriction hydrique** systématique (seulement si Na < 125) ; correction trop rapide de l'hyponatrémie.
6. **Restreindre les protéines** dans l'encéphalopathie.
7. **AINS ou IEC** chez l'ascitique ; **interféron/inhibiteur de protéase** en cirrhose décompensée.
8. Retenir un **SHR** sans épreuve de remplissage par albumine ni exclusion d'une cause organique.
9. Conclure à une cirrhose sur une **élastométrie** mesurée pendant une hépatite aiguë, une cholestase ou un foie cardiaque.
10. Arrêter le **dépistage du CHC** après guérison du VHC ; oublier la **tuberculose péritonéale** devant un GASA < 11 g/L.

## 7. Moyens mnémotechniques (originaux)

- **« 10-15-20-25 »** (règle des 5 de Baveno VII) : exclure, suggérer, éviter l'endoscopie (avec plaquettes > 150), HTPCS probable.
- **« 100/40 jusqu'à 400/160 »** : spironolactone/furosémide, doses de départ et maximales.
- **« 250 PNN, 1,5 puis 1 »** : ILA dès 250 PNN/mm³, albumine 1,5 g/kg à J1 puis 1 g/kg à J3.
- **« 5 litres → 8 grammes »** : albumine 8 g par litre retiré au-delà de 5 L.
- **« Ascitique : ni AINS, ni IEC, ni restriction protéique »**.
- **« Cerveau embrumé → cherche le déclencheur »** : encéphalopathie = facteur déclenchant jusqu'à preuve du contraire.

## 8. Si je n'ai que 5 minutes

1. Cirrhose = fibrose + nodules ; régressible si la cause est supprimée.
2. Bilan étiologique complet (alcool, B+D, C, MASLD, auto-immun, fer, cuivre, vasculaire).
3. Child-Pugh A/B/C et MELD.
4. Élastométrie : < 10 exclut, ≥ 25 HTPCS ; endoscopie évitable si < 20 kPa + plaquettes > 150.
5. HTPCS compensée → carvédilol 6,25 → 12,5 mg/j.
6. Ascite : sel modéré, spironolactone ± furosémide, paracentèse + albumine 8 g/L (> 5 L).
7. Ponction d'ascite à chaque dégradation ; ILA → C3G + albumine J1/J3.
8. IRA → albumine 2 j → SHR : terlipressine + albumine.
9. Encéphalopathie : déclencheur + lactulose ; rifaximine ; pas de restriction protéique.
10. Échographie /6 mois (CHC) ; penser tôt à la transplantation.
