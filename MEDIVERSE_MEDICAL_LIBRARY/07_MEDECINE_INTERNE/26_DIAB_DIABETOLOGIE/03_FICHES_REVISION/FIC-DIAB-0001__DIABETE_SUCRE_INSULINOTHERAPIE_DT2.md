# Fiche — Diabète sucré (RES-MED-091)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-DIAB-0001 (v1.1, statut `audite_corrections_requises`). Aucun fait nouveau. Référentiel principal : **ADA 2026** [S1–S5], consensus ADA/EASD 2022 [S7] ; données algériennes [S11]. Les schémas d'escalade des antidiabétiques autres que la metformine restent `[POSOLOGIE À VÉRIFIER — RCP / protocole local]`.

## 1. Définition (2 lignes)

Groupe de maladies métaboliques caractérisées par une **hyperglycémie chronique** due à un défaut de **sécrétion** et/ou d'**action** de l'insuline ; c'est un **syndrome**, dont la gravité tient aux complications **micro-angiopathiques** (rétine, rein, nerf), **macro-angiopathiques** et aiguës.

## 2. Chiffres et critères à connaître

| Diagnostic (ADA 2026) | Diabète | Prédiabète |
|---|---|---|
| HbA1c | **≥ 6,5 %** (48 mmol/mol) | 5,7–6,4 % |
| Glycémie à jeun | **≥ 1,26 g/L** (7,0 mmol/L) | **1,00–1,25 g/L** (OMS : 1,10–1,25) |
| G2h HGPO 75 g | **≥ 2,00 g/L** (11,1 mmol/L) | 1,40–1,99 g/L |
| Glycémie aléatoire | **≥ 2,00 g/L** + symptômes/crise | — |

**Confirmation obligatoire** sans hyperglycémie franche (2 résultats anormaux). HbA1c non fiable : variants de l'hémoglobine, grossesse, G6PD, VIH, anémie, transfusion.

| Repère | Valeur |
|---|---|
| Algérie (STEPwise) | **8,9 % (2003) → 14,4 % (2016–2017)** ; HbA1c ≥ 7 % chez 64,6 % (Baromètre) [S11] |
| Dépistage | Adulte en surpoids + ≥ 1 facteur ; **tous dès 35 ans** ; tous les 3 ans si normal |
| Objectif HbA1c | **< 7 %** (< 6,5 % si faible risque ; moins strict si fragilité) ; ≥ 2 dosages/an |
| MCG | **TIR > 70 %** ; < 70 mg/dL < 4 % ; < 54 mg/dL < 1 % |
| PA / LDL | < 130/80 ; LDL < 0,70 g/L (haut risque), < 0,55 g/L (prévention secondaire) |
| Albuminurie (RAC) | A1 < 30 ; **A2 30–299** ; A3 ≥ 300 mg/g |
| Insuline DT1 | **≈ 0,5 U/kg/j**, ≈ 50 % basale |
| Insuline basale DT2 | **0,1–0,2 U/kg/j**, **+2 U tous les 3 jours** ; hypoglycémie → −10 à −20 % |
| Metformine | Pas d'initiation si DFGe < 45 ; **45–59 → ≤ 2 000 mg/j ; 30–44 → ≤ 1 000 mg/j ; < 30 → CI** ; max 3 000 mg/j |
| Conversion | 1 g/L = 5,55 mmol/L ; HbA1c 7 % = 53 mmol/mol |

| | Type 1 | Type 2 |
|---|---|---|
| Mécanisme | Destruction **auto-immune** des cellules β | Insulinorésistance + déficit sécrétoire progressif |
| Terrain | Jeune, mince, début bruyant, cétose | > 40 ans, **surpoids (> 90 %)**, hérédité forte, découverte fortuite |
| Biologie | **Auto-anticorps +** (GAD, IA-2, ZnT8, IAA), peptide C bas | Auto-anticorps −, peptide C normal/élevé |
| Traitement | Insuline d'emblée et à vie | Mode de vie + antidiabétiques ; insuline selon évolution |

Autres : **LADA**, **MODY** (autosomique dominant), diabète néonatal (< 6 mois → génétique), pancréatique, endocrinien, médicamenteux (corticoïdes, antipsychotiques, inhibiteurs de points de contrôle), gestationnel.

## 3. Démarche diagnostique

```text
Hyperglycémie → critère ADA (confirmé si asymptomatique)
├─ Classer : phénotype + auto-anticorps si ambigu (jeune, amaigrissement,
│   cétose, insuline rapide) ; peptide C à distance ; génétique si < 6 mois/MODY
├─ Cétonémie si symptomatique, DT1 ou iSGLT2 (≥ 3 mmol/L + acidose = acidocétose)
└─ Bilan du retentissement (au diagnostic du DT2 ; 5 ans après le début du DT1)
    rein : DFGe + RAC ; œil : fond d'œil/rétinographie ; pied : monofilament 10 g,
    diapason, pouls, IPS ; cœur : ECG ; lipides ; FIB-4 si MASLD ;
    TSH (DT1) ; B12 sous metformine
```

## 4. Traitement

```text
DT2 DE L'ADULTE (ADA 2026 / ADA-EASD 2022)
[0] Mode de vie + éducation + PA/LDL/tabac pour tous
[1] Catabolisme, HbA1c > 10 % ou glycémie ≥ 3,00 g/L → INSULINE (± AR GLP-1)
[2] Comorbidité cardio-rénale → choix INDÉPENDANT de l'HbA1c
    ├─ maladie CV athéromateuse / haut risque → AR GLP-1 et/ou iSGLT2 démontrés
    ├─ insuffisance cardiaque → iSGLT2 (FE préservée + obésité : tirzépatide/AR GLP-1)
    ├─ MRD → iSGLT2 (initier si DFGe ≥ 20) ou AR GLP-1 + IEC/ARA2 ; finérénone
    │   si albuminurie (DFGe ≥ 25)
    └─ DFGe < 30 → AR GLP-1 préféré pour la glycémie
[3] Sinon : poids → sémaglutide/tirzépatide ; coût → metformine (historique 1re ligne)
[4] Réévaluer à 3–6 mois, intensifier (pas d'AR GLP-1 + iDPP-4)
[5] GLP-1 avant l'insuline ; puis basale → basal-plus → basal-bolus ou prémélange
```

| Classe | Point fort | Piège / précaution |
|---|---|---|
| Metformine | Peu coûteuse, pas d'hypoglycémie | Digestif ; B12 ; acidose lactique (IRA, hypoxie, iode) |
| Sulfamides | Coût | **Hypoglycémies** (âgé, IRC), poids |
| iDPP-4 | Tolérance | Pas de bénéfice CV ; **jamais avec AR GLP-1** |
| **iSGLT2** | ↓ hospitalisations IC, ↓ progression rénale | Mycoses, déplétion, **acidocétose euglycémique** |
| **AR GLP-1** | ↓ événements CV, poids, rein | Nausées ; rétinopathie si baisse rapide |
| Tirzépatide | Efficacité HbA1c/poids très élevée | Digestif, coût |
| Pioglitazone | MASH | **CI insuffisance cardiaque**, œdèmes, fractures |
| Acarbose | Pas d'hypoglycémie seule | Resucrer au **glucose pur** |

| Insuline | Début | Durée | Usage |
|---|---|---|---|
| Ultrarapides (asparte, lispro, glulisine) | 5–15 min | 3–5 h | Bolus, pompes |
| Rapide humaine | 30 min | 6–8 h | Bolus, IV |
| NPH | 1–2 h | 12–16 h | Basale |
| Analogues lents (glargine, dégludec) | 1–2 h | 20–42 h | Basale, moins d'hypoglycémies nocturnes (U300, dégludec) |

- **DT1** : multi-injections ou pompe, analogues ; insulinothérapie fonctionnelle (ratio insuline/glucides) ; **MCG** ; **glucagon** pour tout patient sous insuline ; délivrance automatisée d'insuline.
- **DT2 sous insuline** : associer un AR GLP-1 ; garder metformine, iSGLT2, AR GLP-1 ; réduire sulfamides/glinides/iDPP-4. Avant d'augmenter la basale : exclure **hypoglycémie nocturne** et **sur-basalisation**.
- **Néphroprotection** : PA < 130/80 ; IEC ou ARA2 si albuminurie (accepter **+30 %** de créatinine) ; **jamais IEC + ARA2** ; protéines 0,8 g/kg/j dès G3.
- **Ramadan** (IDF-DAR 2021) : stratification du risque, éducation pré-Ramadan ; **rompre le jeûne si glycémie < 70 ou > 300 mg/dL** ; adaptations chiffrées `[POSOLOGIE À VÉRIFIER — IDF-DAR 2021, tableaux par classe]`.

## 5. Surveillance et complications

| Complication | Repères |
|---|---|
| Rétinopathie | Fond d'œil au diagnostic (DT2) ; **anti-VEGF 1re intention** si œdème maculaire central ; panphotocoagulation si proliférante ; aspirine non contre-indiquée ; fond d'œil avant intensification rapide |
| Néphropathie | RAC ≥ 30 mg/g et/ou DFGe < 60 > 3 mois ; avis néphrologique si hématurie, déclin rapide, absence de rétinopathie (DT1) |
| Neuropathie | « En chaussettes », achilléens abolis ; autonome (hypotension orthostatique, gastroparésie, vessie, non-perception des hypoglycémies) ; douleur : gabapentinoïdes, duloxétine, tricycliques `[POSOLOGIE À VÉRIFIER — RCP / protocole local]` |
| Pied | Mal perforant plantaire ; **pied de Charcot** (chaud, rouge, peu douloureux → décharge stricte) ; IPS > 1,3 ininterprétable |
| Macroangiopathie | Coronaropathie silencieuse, IC, AVC, AOMI distale ; aspirine 75–162 mg en prévention secondaire |

Surveillance : HbA1c ≥ 2/an ; PA à chaque visite ; lipides, DFGe + RAC, fond d'œil, pieds, neuropathie **annuels** ; K+/créatinine après IEC/ARA2/ARM (finérénone à 1 mois) ; B12 sous metformine. ACCORD : excès de mortalité du contrôle intensif → **individualiser**.

## 6. Pièges classiques

1. Diagnostiquer sur **une seule valeur** chez un asymptomatique.
2. Se fier à l'**HbA1c** en cas d'hémoglobinopathie, hémolyse, transfusion, grossesse, IRC avancée.
3. Confondre l'**HMJ ADA (≥ 1,00 g/L)** et **OMS (≥ 1,10 g/L)**.
4. Croire la **metformine contre-indiquée dès un DFG < 60** (arrêt seulement < 30).
5. Arrêter un IEC/ARA2 pour une **créatinine +30 %** sans hypovolémie.
6. Associer **iDPP-4 + AR GLP-1** ou **IEC + ARA2**.
7. Oublier l'**acidocétose euglycémique** sous iSGLT2 (jeûne, chirurgie, cétogène).
8. Augmenter la basale sans exclure une **hypoglycémie nocturne** ou une **sur-basalisation**.
9. Prendre un **pied de Charcot** pour une cellulite ou une phlébite.
10. Oublier le **fond d'œil avant intensification rapide** ; ne pas anticiper le **Ramadan**.

## 7. Moyens mnémotechniques (originaux)

- **« 6,5 – 1,26 – 2 »** : HbA1c, glycémie à jeun, glycémie à 2 h/aléatoire (g/L) pour le diabète.
- **« 45 on freine, 30 on arrête »** : metformine (pas d'initiation et réduction sous 45 ; arrêt sous 30).
- **« Cœur-rein d'abord, sucre ensuite »** : les comorbidités cardio-rénales dictent iSGLT2/AR GLP-1 indépendamment de l'HbA1c.
- **« 2 U tous les 3 jours »** : titration de la basale dans le DT2.
- **« Demi-dose de basale chez le DT1 »** : ≈ 0,5 U/kg/j, dont ≈ 50 % en basale.
- **« Une seule voie incrétine »** : pas d'iDPP-4 avec un AR GLP-1.

## 8. Si je n'ai que 5 minutes

1. HbA1c ≥ 6,5 %, GAJ ≥ 1,26 g/L, G2h ≥ 2 g/L ; confirmer si asymptomatique.
2. DT1 auto-immun (auto-anticorps), DT2 insulinorésistant ; penser LADA, MODY.
3. Algérie : 14,4 % (STEPwise 2016–2017), contrôle insuffisant.
4. Objectif HbA1c < 7 % individualisé ; TIR > 70 %.
5. Comorbidité CV/IC/MRD → iSGLT2 et/ou AR GLP-1 quel que soit l'HbA1c.
6. Metformine : ≤ 1 000 mg/j si DFGe 30–44, arrêt < 30.
7. Insuline d'emblée si catabolisme, HbA1c > 10 %, glycémie ≥ 3 g/L ; sinon GLP-1 d'abord.
8. Basale 0,1–0,2 U/kg/j, +2 U/3 j ; DT1 0,5 U/kg/j ; glucagon pour tous.
9. Dépistage annuel : RAC + DFGe, fond d'œil, pieds, neuropathie, lipides.
10. Ramadan : stratifier, éduquer, rompre si < 70 ou > 300 mg/dL.
