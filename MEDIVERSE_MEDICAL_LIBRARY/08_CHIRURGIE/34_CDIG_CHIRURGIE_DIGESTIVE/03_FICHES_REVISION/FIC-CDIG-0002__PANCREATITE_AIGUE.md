# Fiche — Pancréatite aiguë (RES-CHI-010)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-CDIG-0002 (v1.1, statut `audite_valide`). Aucun fait nouveau. Référentiels : Atlanta révisée 2012 [S1], IAP/APA 2013 [S2], ACG 2024 [S3] ; essais WATERFALL, PONCHO, POINTER [S4–S6]. Aucune posologie d'antibiotique n'est proposée par le dossier (RCP et protocole local).

## 1. Définition (2 lignes)

Inflammation aiguë du pancréas, de l'œdème interstitiel résolutif à la nécrose avec défaillance multiviscérale. Diagnostic (Atlanta révisée) = **2 critères sur 3** : **douleur** typique, **lipasémie ≥ 3 × LSN**, **imagerie** caractéristique [S1].

## 2. Chiffres et critères à connaître

| Paramètre | Valeur |
|---|---|
| Formes | **Œdémateuse interstitielle** (la plus fréquente) ; **nécrosante ≈ 5–10 %** |
| Phases | Précoce (1re semaine : SIRS, défaillances) ; tardive (complications locales) |
| Gravité (Atlanta) | **Légère** (ni défaillance ni complication) ; **modérément sévère** (défaillance **< 48 h** et/ou complication) ; **sévère** (défaillance **> 48 h**) |
| Défaillance d'organe | **Marshall modifié ≥ 2** (respiratoire, rénal, cardiovasculaire) |
| Causes | **Lithiase 40–70 %** ; **alcool 25–35 %** (ACG 2024) ; hypertriglycéridémie **> 11,3 mmol/L** (≈ 2–5 %) ; idiopathique ≈ 10–20 % |
| TDM pour la nécrose | **≥ 72–96 h** après le début |
| CTSI (Balthazar) | Grade A–E (0–4) + nécrose (0/2/4/6) = 0–10 |
| Ranson | ≥ 3 = grave (nécessite 48 h) `[À VÉRIFIER]` |
| BISAP | Urée > 25 mg/dL, conscience, SIRS, âge > 60, épanchement pleural ; ≥ 3 = mortalité accrue |
| CRP | > 150 mg/L à 48 h `[À VÉRIFIER]` |
| Remplissage (ACG 2024/WATERFALL) | **≤ 1,5 mL/kg/h** sans hypovolémie ; **bolus 10 mL/kg** si hypovolémie |
| WATERFALL | Surcharge 20,5 % (agressif) vs 6,3 % (modéré), sans bénéfice sur la gravité |
| PONCHO | Récidives biliaires 5 % (même hospitalisation) vs 17 % (différée) |
| Encapsulation de la nécrose | **≈ 4 semaines** |

| Complications locales | < 4 semaines | > 4 semaines |
|---|---|---|
| PA interstitielle | Collection liquidienne aiguë (APFC) | **Pseudokyste** (paroi, sans nécrose) |
| PA nécrosante | Collection nécrotique aiguë (ANC) | **Nécrose organisée (WON)** |

## 3. Démarche diagnostique

```text
Douleur épigastrique brutale, intense, transfixiante (antéflexion), vomissements
├─ Lipasémie ≥ 3 × LSN (son niveau ≠ gravité ≠ cause ; ne pas la répéter)
├─ Diagnostic posé ? → pas de TDM ; TDM seulement si DOUTE diagnostique
├─ ÉCHOGRAPHIE CHEZ TOUS dès l'admission (lithiase, voies biliaires)
├─ Gravité : terrain, SIRS (et persistance à 48 h), Marshall, urée, hématocrite,
│   ± BISAP ; CRP à 48 h ; signes de Grey-Turner/Cullen
├─ Étiologie : ALAT précoces (biliaire), triglycérides PRÉCOCES, calcémie, alcool,
│   médicaments ; ECG/troponine (infarctus inférieur), β-hCG
└─ PA « idiopathique » : répéter l'échographie, échoendoscopie/bili-IRM,
    TUMEUR (TIPMP, adénocarcinome) après 40–50 ans, IgG4, génétique
Nécrose infectée : aggravation après 7–10 j, BULLES DE GAZ à la TDM
```

## 4. Traitement

```text
ADMISSION : Ringer lactate, remplissage MODÉRÉ guidé (réévaluer à 3-12-24-48-72 h)
            analgésie multimodale (opioïdes autorisés)
            angiocholite → antibiotiques + CPRE < 24 h
├─ défaillance / SIRS persistant / terrain fragile → soins intensifs
├─ LÉGÈRE → réalimentation orale 24–48 h ; biliaire → CHOLÉCYSTECTOMIE
│           pendant la MÊME hospitalisation
└─ SÉVÈRE / NÉCROSANTE → nutrition ENTÉRALE (sonde nasogastrique) ;
     PAS d'antibioprophylaxie ; TDM à 72–96 h ; pression intravésicale ;
     pseudo-anévrisme → embolisation ;
     NÉCROSE INFECTÉE → antibiotiques pénétrant la nécrose → STEP-UP :
        drainage (percutané rétropéritonéal ou endoscopique transmural)
        → nécrosectomie mini-invasive (endoscopique ou VARD)
        → nécrosectomie ouverte si échec ; idéalement après ~4 semaines
     cholécystectomie différée (> 6 semaines / résolution) si biliaire
```

| Situation | Conduite |
|---|---|
| PA biliaire **avec angiocholite** | **CPRE < 24 h** |
| Obstruction biliaire persistante | CPRE après confirmation (bili-IRM, échoendoscopie) |
| Biliaire sans angiocholite (même prédite sévère) | **Pas de CPRE précoce** (APEC, ACG 2024) |
| Inopérable | Sphinctérotomie (prévention des récidives) |
| Collections stériles, pseudokyste asymptomatique | **Abstention**, quelle que soit la taille |
| Pseudokyste symptomatique/compliqué | Drainage, de préférence endoscopique |
| Hypertriglycéridémie sévère | Insuline IV (± glucosé), plasmaphérèse discutée `[modalités À VÉRIFIER]` |
| Compartiment abdominal | Mesures médicales → décompression chirurgicale en dernier recours |
| Prévention post-CPRE | **Diclofénac ou indométacine rectal 100 mg** juste avant la CPRE (ESGE 2020 : tous ; ACG 2024 : haut risque) ; prothèse pancréatique si haut risque |

- **Sans efficacité démontrée** : IPP (hors indication), somatostatine/octréotide, antiprotéases, aspiration nasogastrique systématique, probiotiques.
- **Chirurgie en urgence** rare : perforation/ischémie digestive, compartiment réfractaire, hémorragie non embolisable ; **laparotomie précoce pour nécrose = délétère**.
- TENSION : step-up endoscopique = moins de fistules pancréatiques ; PANTER : step-up < nécrosectomie ouverte (complications majeures/décès 40 % vs 69 %).

## 5. Surveillance et complications

- Forme sévère : constantes et **diurèse horaires** 24–48 h ; hématocrite, urée, créatinine toutes les 6–12 h ; CRP à 48 h ; glycémie, calcémie ; **pression intravésicale** ; **signes de surcharge** à chaque réévaluation du remplissage.
- Complications : défaillances d'organes (respiratoire, rénale, circulatoire), SDRA, compartiment abdominal, collections, **nécrose infectée**, pseudo-anévrisme hémorragique, thrombose splénique/portale, décompensation de comorbidité (« complication systémique »), syndrome du canal déconnecté.
- À distance : diabète, insuffisance exocrine (élastase fécale), collections résiduelles, bilan étiologique complet.
- Prévention des récidives : **cholécystectomie**, **sevrage alcoolique**, régime pauvre en graisses + fibrates (hypertriglycéridémie), traitement d'une hypercalcémie, arrêt du médicament.
- Algérie : penser à la **rupture d'un kyste hydatique** dans les voies biliaires devant une PA avec cholestase et image kystique (cf. FIC-CDIG-0001).

## 6. Pièges classiques

1. **TDM à l'admission** pour « évaluer la gravité » (nécrose invisible avant 72 h).
2. Corréler le **taux de lipase** à la gravité.
3. Classer la gravité **avant 48 h** (défaillance possiblement transitoire).
4. **Antibioprophylaxie** systématique dans une PA nécrosante.
5. **CPRE systématique** dans toute PA biliaire.
6. **Jeûne prolongé** d'une PA légère ; **nutrition parentérale d'emblée** dans une PA sévère.
7. **Remplir massivement** (surcharge, SDRA, compartiment abdominal).
8. **Opérer précocement** une nécrose ou drainer une collection stérile asymptomatique.
9. Reporter de plusieurs mois la **cholécystectomie** d'une PA biliaire légère.
10. Oublier/doser trop tard **triglycérides et calcémie** ; méconnaître une perforation d'ulcère, un infarctus inférieur ou une **tumeur** après 40–50 ans.

## 7. Moyens mnémotechniques (originaux)

- **« 2 sur 3, 3 fois »** : 2 critères sur 3, dont une lipase ≥ 3 × LSN.
- **« 48 h trie, 72 h montre »** : 48 h pour classer la gravité (défaillance transitoire ou persistante) ; ≥ 72 h pour voir la nécrose au scanner.
- **« Biliaire légère : la vésicule part avant le patient »** : cholécystectomie pendant la même hospitalisation.
- **« Angiocholite = CPRE ; sinon, patience »**.
- **« Step-up : drainer, puis enlever, puis ouvrir — et attendre 4 semaines »**.
- **« Ringer, mais sans noyer »** : Ringer lactate, remplissage modéré.

## 8. Si je n'ai que 5 minutes

1. Diagnostic : 2/3 (douleur, lipase ≥ 3 × LSN, imagerie) ; lipase sans valeur pronostique.
2. Échographie chez tous ; TDM seulement si doute, ou après 72–96 h pour la nécrose.
3. Atlanta : légère / modérément sévère (< 48 h) / sévère (> 48 h) ; Marshall ≥ 2.
4. Causes : lithiase, alcool, triglycérides > 11,3 mmol/L, hypercalcémie, médicaments, tumeur.
5. Ringer lactate, remplissage modéré (≤ 1,5 mL/kg/h ; bolus 10 mL/kg si hypovolémie).
6. Opioïdes autorisés ; réalimentation précoce ; entérale > parentérale.
7. Pas d'antibioprophylaxie ; CPRE < 24 h seulement si angiocholite.
8. Cholécystectomie pendant la même hospitalisation (légère) ; différée si nécrosante.
9. Nécrose infectée : antibiotiques → step-up, après ~4 semaines si possible.
10. Collections stériles et pseudokystes asymptomatiques : abstention.
