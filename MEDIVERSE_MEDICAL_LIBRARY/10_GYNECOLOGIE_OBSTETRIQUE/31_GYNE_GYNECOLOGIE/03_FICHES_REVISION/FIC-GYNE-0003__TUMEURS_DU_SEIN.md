# Fiche — Tumeurs du sein (RES-CHI-062)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-GYNE-0003 (v1.1, statut `audite_corrections_requises`). Aucun fait nouveau ; le dossier ne détaille **volontairement pas** les posologies des traitements anticancéreux (protocoles des centres anticancer et RCP). Références : **ESMO 2024** (cancer précoce) [S1], **OMS 2019** [S2, S3], **BI-RADS 5e édition** [S4], **GLOBOCAN 2022** [S5], **AJCC 8e édition** [S9].

## 1. Définition (2 lignes)

Lésions **bénignes** (majoritaires chez la femme jeune), **frontières/à risque** (B3) et **malignes**, dominées par les **carcinomes** nés des **unités terminales ductulo-lobulaires** ; **in situ** = membrane basale respectée (pas de risque métastatique en soi), **infiltrant** = franchie. Le traitement dépend du **stade** et surtout du **sous-type biologique**.

## 2. Chiffres et critères à connaître

| Paramètre | Valeur |
|---|---|
| **Algérie (GLOBOCAN 2022)** | **14 601 cas**, **41,3 %** des cancers féminins, 22,6 % de tous les cancers : **1er cancer de la femme** |
| Sétif | Incidence 10,4 → 19,6/100 000 (1986–2005) ; **+ 8,2 %/an** (1996–2010) |
| Homme | ≈ 1 % des cancers du sein `[À VÉRIFIER]` (rechercher **BRCA2**) |
| Histologie (OMS 2019) | **NST ≈ 70–80 %** (« médullaire » = simple aspect du NST) ; **lobulaire ≈ 10–15 %** (perte de l'**E-cadhérine**, multifocal, bilatéral, mal vu en mammographie) ; tubuleux, cribriforme, mucineux : bon pronostic |
| Grade de Nottingham | Tubes + noyaux + mitoses (1–3 chacun) : **3–5 = I ; 6–7 = II ; 8–9 = III** |
| RE/RP | **Positifs si ≥ 1 %** (RE faible 1–10 % ≈ triple négatif) |
| HER2 | **3+** positif ; **2+ → ISH** ; 0 négatif ; **1+ ou 2+/ISH− = « HER2-low »** (cible du trastuzumab deruxtécan au stade métastatique) |
| TNM (AJCC 8) | T1 ≤ 20 mm ; T2 20–50 ; T3 > 50 ; **T4b** peau (peau d'orange, ulcération) ; **T4d inflammatoire** ; N1 axillaire mobile ; N2 fixé ou mammaire interne isolé ; N3 sous/sus-claviculaire |
| Drainage | Axillaire ≈ 75 % (**niveaux de Berg I-II-III** / petit pectoral), mammaire interne, sus-claviculaire |

| Sous-type | Profil | Traitement systémique |
|---|---|---|
| **Luminal A-like** | RE+, RP élevé, HER2−, Ki-67 bas | **Hormonothérapie** |
| **Luminal B-like HER2−** | RE+, Ki-67 élevé/RP bas | Hormonothérapie **± chimiothérapie** (± CDK4/6 si haut risque) |
| **Luminal B-like HER2+** | RE+, HER2+ | Chimiothérapie + **anti-HER2** + hormonothérapie |
| **HER2-enrichi** | RE−, RP−, HER2+ | Chimiothérapie + **anti-HER2** |
| **Triple négatif** | RE−, RP−, HER2− | **Chimiothérapie** ± pembrolizumab ± PARP (BRCA) |

| BI-RADS (ACR 2013) | Sens | Conduite |
|---|---|---|
| 0 | Incomplet | Compléments |
| 1 / 2 | Négatif / bénin | Surveillance habituelle |
| **3** | Probablement bénin (**≤ 2 %**) | **Contrôle rapproché** (6 mois, puis 12 et 24 mois) |
| **4A/4B/4C** | Suspect (> 2–10 / > 10–50 / > 50– < 95 %) | **Biopsie** |
| **5** | **≥ 95 %** | **Biopsie** |
| 6 | Cancer prouvé | Traitement |

**Facteurs de risque** : **âge**, **BRCA1/2** et antécédents familiaux, hyperplasie atypique, néoplasie lobulaire, **irradiation thoracique jeune**, puberté précoce, ménopause tardive, nulliparité, 1re grossesse > 30 ans, **THM combiné**, obésité post-ménopausique, **alcool**, densité mammaire ; protecteurs : multiparité, **allaitement**, activité physique.

## 3. Démarche diagnostique

```text
TRIPLE ÉVALUATION : CLINIQUE + IMAGERIE + HISTOLOGIE (microbiopsie AVANT toute chirurgie)
Clinique bilatérale : taille, quadrant, consistance, mobilité (Tillaux), peau (peau d'orange,
  rétraction), mamelon (Paget), écoulement, aisselles, sus-claviculaires, schéma daté
├─ < 30–35 ans → ÉCHOGRAPHIE
│    kyste simple (BI-RADS 2) | fibroadénome typique (BI-RADS 3 : surveillance) | 4–5 : biopsie
└─ ≥ 30–35 ans → MAMMOGRAPHIE bilatérale + ÉCHOGRAPHIE
     1–2 : bénin si concordant | 3 : surveillance rapprochée | 4–5 : MICROBIOPSIE
     (macrobiopsie sous stéréotaxie si microcalcifications)
→ Concordance radio-histologique OBLIGATOIRE (BI-RADS 5 + biopsie bénigne = rebiopsie/exérèse)
→ Compte rendu : type, grade, RE, RP, HER2, Ki-67 → bilan d'extension selon stade
→ oncogénétique si critères → RCP
```

- Malignité : mammographie — opacité **stellaire**, contours irréguliers, **distorsion**, **microcalcifications pléomorphes/linéaires segmentaires** ; échographie — masse hypoéchogène irrégulière, **« plus haute que large »**, cône d'ombre.
- **IRM** : lobulaire, seins denses, discordances, réponse au néo-adjuvant, **BRCA**, adénopathie axillaire isolée.
- **Bilan d'extension (ESMO 2024)** : **pas** de routine pour petite tumeur cN0 asymptomatique ; **TDM TAP + scintigraphie osseuse ou TEP-TDM** si **≥ T3**, **N+**, **inflammatoire**, biologie agressive, symptômes, ou avant néo-adjuvant `[S1 — modalités À VÉRIFIER]` ; **CA 15-3 : ni diagnostic ni dépistage** ; FEVG avant anthracyclines/anti-HER2 ; **préservation de la fertilité**.
- Bénin : **fibroadénome** (15–35 ans, mobile ; exérèse si > 3 cm, croissance, gêne), **phyllode** (40–50 ans, croissance rapide ; exérèse à **marges saines**, **pas de geste axillaire**), **kyste** (anéchogène), **papillome** (**écoulement unipore sanglant** → exérèse), lésions **B3** (exérèse ou macrobiopsie).
- Différentiels : **sein inflammatoire** hors allaitement = **cancer inflammatoire** jusqu'à preuve du contraire (biopsie) ; écoulement physiologique (bilatéral, multipore) vs suspect (unipore, sanglant, spontané) ; **gynécomastie** vs cancer chez l'homme ; Paget vs eczéma (biopsie si persistance).

## 4. Traitement

```text
CCIS → conservateur (marges saines) + RADIOTHÉRAPIE, ou mastectomie ; PAS de curage
       (sentinelle seulement si mastectomie/suspicion d'invasion) ; hormonothérapie si RH+
RH+/HER2− opérable → chirurgie première (conservatrice + ganglion sentinelle)
       → chimiothérapie adjuvante si haut risque (N, grade, Ki-67, signature génomique)
       → radiothérapie → hormonothérapie 5–10 ans (± CDK4/6i, ± olaparib si BRCA,
         ± bisphosphonate si ménopausée)
HER2+ (T2 ou N+) → NÉO-ADJUVANT chimio + trastuzumab ± pertuzumab → chirurgie
       → RÉSIDU : T-DM1 / réponse complète : anti-HER2 pour 1 AN au total → RT
       → hormonothérapie si RH+ ; petites N0 : chirurgie puis chimio allégée + trastuzumab
TRIPLE NÉGATIF (T2 ou N+) → paclitaxel-carboplatine puis AC + PEMBROLIZUMAB
       (KEYNOTE-522, poursuivi en adjuvant) → chirurgie → RÉSIDU : capécitabine ou
       olaparib (BRCA, OlympiA) → RT
INFLAMMATOIRE / LOCALEMENT AVANCÉ → systémique premier → MASTECTOMIE + CURAGE
       (PAS de ganglion sentinelle si inflammatoire) → RT → adjuvants
MÉTASTATIQUE → RH+/HER2− : hormonothérapie + CDK4/6i ; HER2+ : trastuzumab-pertuzumab
       + taxane puis trastuzumab deruxtécan ; TN : chimio ± pembrolizumab (PD-L1+),
       PARP (BRCA) ; HER2-low : trastuzumab deruxtécan ; os : bisphosphonates/dénosumab
```

| Moyen | Points clés (dossier) |
|---|---|
| Traitement conservateur | Tumorectomie/oncoplastie **+ radiothérapie** = survie équivalente à la mastectomie si éligible ; marges saines (« pas de tumeur à l'encre » pour l'infiltrant `[À VÉRIFIER]`) |
| Mastectomie | Tumeur volumineuse/sein, **multicentricité**, **inflammatoire**, CI/refus de RT, récidive, choix, BRCA (option) |
| **Ganglion sentinelle** | Standard **cN0** ; curage (I-II) si atteinte prouvée persistante ou inflammatoire ; désescalade pour 1–2 sentinelles + conservateur + RT `[S1 — À VÉRIFIER]` |
| Radiothérapie | Après conservateur (hypofractionnement 40 Gy/15 fr, voire 26 Gy/5 fr `[S1 — À VÉRIFIER]`) ; après mastectomie si N+ (surtout ≥ 4), T3–T4, inflammatoire |
| **Tamoxifène** | RH+ **non ménopausée** ; EI : **thromboses**, **cancer de l'endomètre** (explorer toute métrorragie), bouffées ; **tératogène** |
| **Anti-aromatase** | RH+ **ménopausée** (ou sous suppression ovarienne) ; **arthralgies, ostéoporose** (ostéodensitométrie) |
| Anthracyclines → taxanes | Neutropénie fébrile, **cardiotoxicité**, neuropathie |
| **Trastuzumab** | **1 an** ; **FEVG /3 mois** |
| Pembrolizumab, olaparib, CDK4/6i | Effets immuno-induits ; anémie ; neutropénie, diarrhée (abémaciclib), QT/cytolyse (ribociclib) |

Algérie : centres anticancer ; leviers = **examen clinique des seins**, orientation rapide, **microbiopsie** et **immunohistochimie** (RE, RP, HER2) ; diagnostic souvent tardif `[À VÉRIFIER]` ; accès aux thérapies ciblées variable `[À VÉRIFIER]`.

## 5. Surveillance et complications

- Clinique /3–6 mois × 2–3 ans, /6–12 mois jusqu'à 5 ans, puis annuelle `[S1 — À VÉRIFIER]` ; **mammographie annuelle** (± IRM si haut risque génétique) ; **pas** de marqueurs ni d'imagerie systémique chez l'asymptomatique.
- Tamoxifène → métrorragies ; anti-aromatase → ostéodensitométrie, lipides ; anti-HER2/anthracyclines → FEVG ; **observance** de l'hormonothérapie ; lymphœdème ; **contraception non hormonale** (DIU au cuivre).
- Complications du cancer évolué : os (**compression médullaire**, **hypercalcémie**, fractures), plèvre, foie, lymphangite, **cerveau** (HER2+ et triple négatif), ulcération locale.
- Pronostic : **ganglions** (facteur majeur), taille, grade, RH, HER2, Ki-67, emboles, âge jeune, **réponse complète** après néo-adjuvant, BRCA (prédictif).
- Prévention : activité physique, poids, alcool, allaitement, prudence THM ; **BRCA** : IRM annuelle précoce, chirurgie prophylactique à discuter ; dépistage organisé **50–74 ans tous les 2 ans** (Europe, début possible à 45 ans `[À VÉRIFIER]`) ; Algérie : **zones pilotes** (Plan cancer 2015-2019) ; autopalpation sans bénéfice démontré sur la mortalité `[À VÉRIFIER]`.

## 6. Pièges classiques

1. **Échographie rassurante seule** après 35 ans, sans mammographie.
2. **Tumorectomie diagnostique** d'emblée au lieu d'une **microbiopsie**.
3. **CA 15-3** pour diagnostiquer ou dépister.
4. « Abcès » hors allaitement traité par antibiotiques répétés **sans biopsie** (cancer inflammatoire).
5. **Ganglion sentinelle dans un cancer inflammatoire**.
6. Confondre **BI-RADS 3** (surveillance) et **BI-RADS 4** (biopsie).
7. Opérer largement un **CLIS classique** (marqueur de risque) — mais traiter le **CLIS pléomorphe** comme un CCIS.
8. **Anti-aromatase seul** chez une femme **non ménopausée**.
9. Négliger une **métrorragie sous tamoxifène** ; oublier la **FEVG** sous trastuzumab/anthracyclines.
10. **Contraception œstroprogestative** après cancer du sein ; méconnaître le **cancer du sein de l'homme** (BRCA2).

## 7. Moyens mnémotechniques (originaux)

- **« Toucher, voir, piquer — puis seulement opérer »** (triple évaluation, microbiopsie avant chirurgie).
- **« Moins de 35 : écho ; plus de 35 : mammo + écho »**.
- **« BI-RADS 3 : on regarde ; 4 et 5 : on pique »**.
- **« Tubes, noyaux, mitoses : 3 à 9 points, 3 grades »** (Nottingham).
- **« Avant la ménopause, tamoxifène ; après, aromatase »**.
- **« HER2 : un an de trastuzumab, et le cœur à l'œil »**.
- **« Sein rouge sans bébé = biopsie »** ; **« Inflammatoire : chimio, mastectomie, curage, rayons — jamais de sentinelle »**.

## 8. Si je n'ai que 5 minutes

1. 1er cancer de la femme algérienne : 14 601 cas (41,3 %) en 2022.
2. Triple évaluation ; microbiopsie avant toute chirurgie ; concordance radio-histologique.
3. < 35 ans : échographie ; ≥ 35 ans : mammographie + échographie.
4. BI-RADS 3 surveillance (≤ 2 %) ; 4–5 biopsie.
5. NST 70–80 %, lobulaire 10–15 % (E-cadhérine, IRM) ; Nottingham I–III.
6. RE/RP ≥ 1 % ; HER2 3+ ou 2+ ISH+ → 5 sous-types.
7. Conservateur + RT ; sentinelle si cN0 ; curage si atteinte persistante ou inflammatoire.
8. RH+ : hormonothérapie 5–10 ans ; HER2+ : trastuzumab 1 an (néo-adjuvant si T2/N+, T-DM1 si résidu).
9. Triple négatif : néo-adjuvant + pembrolizumab ; olaparib si BRCA.
10. Surveillance : clinique + mammographie annuelle ; pas de CA 15-3 ; métrorragie sous tamoxifène → endomètre.
