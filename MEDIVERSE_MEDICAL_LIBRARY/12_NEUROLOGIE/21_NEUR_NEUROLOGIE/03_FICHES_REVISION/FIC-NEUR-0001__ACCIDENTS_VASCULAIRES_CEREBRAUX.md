# Fiche — Accidents vasculaires cérébraux (RES-MED-030)

> Fiche de révision **dérivée exclusivement** du dossier audité DOS-NEUR-0001 (v1.1, statut `audite_corrections_requises`). Aucun fait nouveau ; doses identiques au dossier. Références : **AHA/ASA 2026** (infarctus) [S1], **ESO 2021/2023** (thrombolyse, ténectéplase) [S2, S3], **ESO-ESMINT** (thrombectomie) [S4], **AHA/ASA 2022** (HIC) [S7], **AHA/ASA 2023** (HSA) [S8]. Recommandations nationales algériennes sur la reperfusion non retrouvées `[À VÉRIFIER]`.

## 1. Définition (2 lignes)

Déficit neurologique **brutal**, le plus souvent focal, par lésion vasculaire de l'encéphale, de la moelle ou de la rétine : **infarctus** (≈ 8/10), **HIC**, **HSA**, **TVC**. La clinique ne distingue pas ischémie et hémorragie : **l'imagerie est la première étape**.

## 2. Chiffres et critères à connaître

| Paramètre | Valeur |
|---|---|
| AIT | Dysfonction focale brève **sans infarctus à l'imagerie** (définition **tissulaire**, plus temporelle) ; évaluation **≤ 24 h** ; ABCD2 ne doit pas exclure |
| Heure de début | **Dernière heure vue normale** (AVC du réveil = heure du **coucher**) |
| DSC | Normal ≈ 50 mL/100 g/min ; < 20 : silence électrique ; < 10 : mort neuronale ; autorégulation PAM ≈ 60–150 mmHg (abolie dans la zone ischémique) |
| NIHSS | 0–42 ; **sous-estime la circulation postérieure** |
| ASPECTS | 0–10 (10 régions sylviennes) ; **≥ 6** = infarctus limité |
| Score ICH (0–6) | GCS 3–4 (2) / 5–12 (1) ; volume ≥ 30 mL (1) ; inondation ventriculaire (1) ; infratentoriel (1) ; âge ≥ 80 (1) |
| WFNS (HSA) | I GCS 15 ; II 13–14 sans déficit ; III 13–14 avec déficit ; IV 7–12 ; V 3–6 |
| mRS | 0–6 ; 0–2 = indépendance |
| Algérie | AVC = **1re cause d'invalidité, 2e cause de décès** ; **registre national INSP (déc. 2024)** ; registre de Constantine ; penser **cardiopathie rhumatismale** et **Behçet** (TVC) |

| Pression artérielle à la phase aiguë | Cible |
|---|---|
| Avant thrombolyse | **< 185/110** puis **< 180/105 pendant 24 h** |
| Infarctus non thrombolysé | Ne traiter que si **> 220/120** (≈ −15 % sur 24 h) ou comorbidité |
| Après thrombectomie recanalisée | **Ne pas viser PAS < 140** |
| HIC | Précoce (≈ 2 h), PAS **≈ 140 (130–150)**, éviter < 130 et les chutes brutales |
| HSA avant exclusion | Contrôle (souvent PAS < 160) sans hypotension |

Molécules IV titrables : nicardipine, urapidil, labétalol `[POSOLOGIE À VÉRIFIER — RCP / protocole local]`.

## 3. Démarche diagnostique

```text
DÉFICIT BRUTAL (FAST / BE-FAST) → appel des secours → centre capable de thrombolyser
Recueillir : heure (dernière vue normale), ANTICOAGULANT (molécule, dernière prise),
             mRS antérieur, GLYCÉMIE CAPILLAIRE (hypoglycémie = simulateur n° 1)
│
├─ NIHSS rapide + IMAGERIE IMMÉDIATE (IRM ; à défaut TDM + angioscanner ± perfusion)
│     TDM : hyperdensité = sang ; signes précoces, artère hyperdense, ASPECTS
│     IRM : diffusion+ en minutes ; DWI+/FLAIR− = lésion < 4,5 h probable ; T2* = sang
│     Angio : occlusion carotide interne / M1 / basilaire
├─ Biologie : SEULE la glycémie est obligatoire avant thrombolyse (sauf suspicion de
│     coagulopathie ou anticoagulant) ; ECG + troponine sans retarder (AHA/ASA 2026)
└─ Bilan étiologique (24–72 h) : vaisseaux cervicaux/intracrâniens, ECG + monitorage
     ≥ 24 h (FA paroxystique), ETT ± ETO, lipides, HbA1c ; jeune : SAPL, Behçet, toxiques
```

**Topographie** : ACM superficielle (brachio-faciale, HLH, **aphasie** si dominant, **négligence/anosognosie** si mineur, déviation vers la lésion) ; ACM profonde (hémiplégie **proportionnelle**) ; ACA (**crurale**, comportement, grasping) ; ACP (**HLH isolée**, alexie sans agraphie) ; **Wallenberg** (homolatéral : V thermo-algique, IX-X, **Claude Bernard-Horner**, vestibulaire, cérébelleux ; controlatéral : thermo-algique **épargnant la face** ; pas de déficit moteur) ; basilaire (vigilance, tétraparésie, **locked-in**) ; lacunes (moteur pur, sensitif pur, dysarthrie-main malhabile, hémiparésie ataxique).

**TOAST** : athérosclérose des gros troncs ; **cardio-embolie** (FA, **valvulopathie rhumatismale**, prothèse mécanique, endocardite) ; petites artères ; autre cause (**dissection** : cervicalgie + CBH) ; indéterminée (ESUS).

**HSA** : céphalée **maximale en < 1 min** → **scanner** → si normal et suspicion : **PL** (xanthochromie) → angioscanner/artériographie.

Simulateurs : hypoglycémie, Todd, migraine avec aura (marche 5–30 min), HSD, tumeur/abcès, sepsis, fonctionnel, vertige périphérique (HINTS).

## 4. Traitement

```text
HÉMORRAGIE
├─ HIC → PAS ≈ 140 ; antagonisation ; neurochirurgie si cervelet/hydrocéphalie
└─ HSA → nimodipine, exclusion de l'anévrisme < 24 h, euvolémie
INFARCTUS
├─ < 4,5 h, déficit INVALIDANT, pas de CI → THROMBOLYSE
├─ Heure inconnue → DWI/FLAIR ou perfusion (4,5–9 h « peut être raisonnable », AHA/ASA 2026)
├─ Occlusion d'un gros tronc → THROMBECTOMIE, sans omettre la thrombolyse si éligible
└─ Déficit mineur non invalidant → antiplaquettaire(s), pas de thrombolyse
```

| Traitement | Schéma (dossier) |
|---|---|
| **Altéplase** | **0,9 mg/kg (max 90 mg)** : 10 % bolus 1 min, 90 % en 60 min |
| **Ténectéplase** | **0,25 mg/kg (max usuel 25 mg) bolus unique** ; 0,40 mg/kg non recommandé ; ESO 2023 : **préféré** si occlusion d'un gros tronc ; AHA/ASA 2026 : équivalent |
| CI de thrombolyse | Hémorragie, hypodensité étendue, PA > 185/110 non contrôlable, TC grave/neurochirurgie ≤ 3 mois, hémorragie active/digestive récente, dissection aortique, **endocardite**, tumeur intra-axiale, **plaquettes < 100 000**, **INR > 1,7** ; à discuter : AOD < 48 h (idarucizumab si dabigatran), grossesse, antécédent d'HIC ; corriger une glycémie < 50 mg/dL |
| Complications de thrombolyse | HIC symptomatique (quelques %), **angio-œdème** (IEC) ; aggravation → arrêt + scanner ; fibrinogène/cryo, acide tranexamique `[POSOLOGIE À VÉRIFIER — protocole local]` |
| **Thrombectomie** | CI/M1 **0–6 h** (NIHSS ≥ 6, ASPECTS ≥ 6, mRS 0–1) ; **6–24 h** sur critères DAWN/DEFUSE 3 ; **infarctus étendus** sélectionnés jusqu'à 24 h `[À VÉRIFIER — seuils AHA/ASA 2026]` ; **basilaire jusqu'à 24 h** ; moyen calibre : pas de bénéfice systématique (2025) ; pas de limite d'âge en soi |
| Aspirine | **160–300 mg** dans les 24–48 h ; **après thrombolyse : attendre le scanner de 24 h** |
| Aspirine + clopidogrel | Charge puis **75 mg/j**, **21 jours**, débutée ≤ 24 h : infarctus mineur (**NIHSS ≤ 3**) ou **AIT à haut risque** ; ticagrélor alternative `[À VÉRIFIER]` |
| FA | AOD **précoce**, modulé par la taille de l'infarctus `[À VÉRIFIER — ELAN, TIMING]` ; **pas d'héparine curative systématique** en aigu (sauf TVC) |
| HIC sous AVK | **CCP** (poids, INR) **+ vitamine K IV 10 mg** |
| HIC sous dabigatran | **Idarucizumab 5 g IV** |
| HIC sous anti-Xa | Andexanet alfa sinon CCP `[POSOLOGIE À VÉRIFIER — RCP / protocole local]` |
| HIC sous HNF / antiplaquettaire | Protamine / **pas de transfusion plaquettaire** sans chirurgie ; **pas de prophylaxie antiépileptique** |
| **Nimodipine** (HSA) | **60 mg /4 h per os pendant 21 jours** (réduire les prises si hypotension, RCP) ; euvolémie ; **pas de restriction hydrique** si hyponatrémie |
| Infarctus sylvien malin | **Hémicraniectomie** précoce (≤ 48 h) ; > 60 ans : décision partagée |
| Mesures générales | **UNV** ; O₂ seulement si SpO₂ ≤ 94 % ; **pas de contrôle glycémique intensif** (80–130 mg/dL) ; antipyrétique ; compression pneumatique ± HBPM ; **test de déglutition** avant toute prise orale |

**Prévention secondaire** : antiplaquettaire (non cardio-embolique), **AOD/AVK si FA** (AVK pour prothèse mécanique), **statine haute intensité** (LDL ≤ 70 mg/dL, cibles nord-américaines), PA < 130/80 `[À VÉRIFIER — S11]`, **endartériectomie < 2 semaines** pour sténose symptomatique **70–99 %** (moindre 50–69 %), fermeture du FOP chez le jeune sélectionné.

## 5. Surveillance et complications

- Post-thrombolyse : NIHSS + PA **/15 min × 2 h, /30 min × 6 h, puis /h jusqu'à 24 h** ; **imagerie à 24 h** avant antithrombotique.
- Monitorage cardiaque, SpO₂, glycémie, température, déglutition ; HIC : GCS/pupilles ; HSA : examen pluriquotidien (ischémie retardée **J3–J14**), **natrémie quotidienne**.
- Complications neurologiques : œdème (max J2–J5), engagement, transformation hémorragique, crises, récidive précoce, expansion d'hématome, hydrocéphalie, resaignement (HSA, maximal les premières heures).
- Complications générales : **pneumopathie d'inhalation**, TVP/EP, IU, escarres, dépression, spasticité, épaule douloureuse.
- HIC : **pas de limitation thérapeutique trop précoce** (attendre ≥ 24–48 h : prophétie autoréalisatrice).

## 6. Pièges classiques

1. Confondre **AIT et infarctus mineur** (lésion en diffusion = infarctus).
2. Attendre le **bilan biologique complet** avant de thrombolyser (seule la glycémie est indispensable).
3. Abaisser la PA d'un **infarctus non thrombolysé** à 150/90.
4. **Héparine curative** en urgence dans un infarctus cardio-embolique.
5. Oublier l'**heure de la dernière prise d'AOD**.
6. Dater l'AVC du réveil à l'**heure du réveil**.
7. Thrombolyser un **déficit mineur non invalidant**.
8. **PL avant le scanner** devant une céphalée en coup de tonnerre.
9. **Restreindre l'eau** devant une hyponatrémie d'HSA ; **prophylaxie antiépileptique** systématique dans l'HIC.
10. Récuser la reperfusion pour **l'âge** seul ; ignorer que le **NIHSS sous-estime** les AVC postérieurs.

## 7. Moyens mnémotechniques (originaux)

- **« 185/110 pour ouvrir, 180/105 pour tenir »** (avant / pendant 24 h après thrombolyse).
- **« 0,9 ou 0,25 : un dixième en bolus pour l'une, tout en bolus pour l'autre »** (altéplase vs ténectéplase).
- **« 4,5 pour lyser, 6 puis 24 pour retirer »**.
- **« Le sucre d'abord, le sang ensuite »** : glycémie capillaire puis imagerie.
- **« Coucher, pas réveil »** (heure de début de l'AVC du réveil).
- **« HSA : scanner, puis piquer ; nimodipine 60 toutes les 4, 21 jours »**.
- **« Wallenberg : face d'un côté, corps de l'autre, jamais de paralysie »**.

## 8. Si je n'ai que 5 minutes

1. AVC = urgence : secours, centre capable de thrombolyser, imagerie immédiate.
2. Glycémie capillaire = seul examen biologique indispensable avant thrombolyse.
3. Thrombolyse < 4,5 h si déficit invalidant : altéplase 0,9 mg/kg ou ténectéplase 0,25 mg/kg.
4. Heure inconnue : DWI/FLAIR ou perfusion.
5. Thrombectomie : gros tronc antérieur ≤ 6 h, puis ≤ 24 h sur imagerie ; basilaire ≤ 24 h ; ne pas omettre la thrombolyse.
6. PA < 185/110 puis < 180/105 ; HIC : PAS ≈ 140 ; non thrombolysé : seulement > 220/120.
7. AIT/infarctus mineur : aspirine + clopidogrel 21 j.
8. HIC sous anticoagulant : CCP + vitamine K (AVK), idarucizumab (dabigatran).
9. HSA : scanner → PL ; nimodipine ; anévrisme exclu < 24 h ; euvolémie.
10. UNV, déglutition, prévention secondaire (statine, FA, carotide 70–99 % < 2 semaines) ; registre INSP 2024.
